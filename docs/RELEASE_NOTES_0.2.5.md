# MCP_CREO_MechDog v0.2.5

完成指定的 1、2、3、4、8、10 项改进。提供 **80 个可用 MCP 工具**、**九个 MIT 原生混合种子**及源码安装包。本版保留可编辑的 Creo 原生参数化特征，仍为预发布，完整 Creo 覆盖未完成。

## 本轮变化

- 能力报告与实际工具列表一致。禁用操作隐藏并在入队前拒绝；已验收的直接混合工具现已开放。
- `creo_get_job(detail="compact")` 与 `creo_list_jobs` 精简响应；get 默认 full 保持兼容，list 默认 compact。
- 新增 3/4/6 截面的直线与平滑种子。与原有两截面直线/平滑、五截面平滑合计九个，数量/模式自动匹配，SHA256 校验，安装时自动注册。
- 验证曲线恒截面扫掠、切除、曲面与加厚及对称薄壁，修正薄壁侧向定义被 Creo 重置的问题。
- 草图新增 `dimensioning="auto" / "autodim" / "coordinates"`。大坐标和复杂直线/圆弧轮廓使用原生坐标尺寸，写入前后核对实际几何；不使用坐标缩放或刚性求解。整体几何编辑保持草图及下游实体特征 ID，重新生成尺寸。
- `creo_loft` 与计划 `loft` 支持直接原生混合及已有受管零件追加。支持面尺寸改变后读取实际截面位置检查顺序；失败追加恢复已有模型及别名。同步选择回调 DLL 独立缓存，减少无关修改引发的重建。

## 验证

57 项自动检查通过。真实 MCP 协议验证版本、工具列表与精简查询；Creo 实机验收覆盖六个新种子的原生创建与重绑定、四个扫掠分支、六类草图、已有底座追加混合、实际截面位置修改与拒绝。适用案例检查原生特征 ID、参数修改、实体体积及 STL、保存擦除重载、故意失败回滚和恢复后的实际模型。[逐项结果](PROGRESS_025.md)、[结构化证据](validation_increment_025.json)。

此前 0.2.4 验收标签保留为历史记录；这些开发验收完成后升版为 0.2.5。本轮没有重跑全部既有模块的历史套件，不据此扩大工程图、钣金、装配、专业模块等能力范围。

## 安装与迁移

下载 `MCP_CREO_MechDog-0.2.5-source.zip`，解压到可写目录，按 [INSTALL.md](INSTALL.md) 运行 `setup.ps1`，生成本机环境与客户端配置。源码已经内附九个种子；独立 `MCP_CREO_MechDog-0.2.5-seed-library.zip` 用于单独迁移。两包分别提供 `.zip.sha256`。

升级时等待任务完成并停止 MCP 服务，保留 `config.json`、`models/`、`jobs/`，更新公开源码后重跑安装，重启客户端。调用 `creo_capabilities` 检查版本 0.2.5 与 80 个可用工具，`creo_list_seeds` 检查九个文件。首次加载或更新同步回调 DLL 时，Creo 可能需要使用者手动确认安全警告。目标机仍需匹配的 Creo/Toolkit SDK、编译器及许可；不复制另一台电脑的虚拟环境、二进制或会话 ID。[跨电脑步骤](MIGRATION.md)。

## 能力边界

直接混合限受管独立 XY 草图、实际 Z 严格递增、默认实体增材，支持 straight/smooth；不提供非平行、切除/曲面、新实体或端点相切/曲率控制。坐标尺寸限主平面的直线、中心线、矩形、多段线、圆、圆弧，无用户显式尺寸/约束；样条/椭圆与任意方向面沿用 autodim。扫掠为恒定截面，其他路径/方向/相交组合需本机验证。九个种子不意味着每种数量和轮廓已验证。

模具、NC、仿真、线缆等专业模块仍未完整封装。本版本不承诺完整覆盖 Creo。项目自身代码、文档与原创种子采用 MIT，不提供 Creo、SDK 或 PTC 许可授权。
