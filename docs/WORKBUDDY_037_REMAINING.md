# 0.3.7 剩余事项的公开 MCP 验收

本提示词仅用于最终部署的黑盒验收。只调用已连接 MCP_CREO_MechDog_dev 的公开工具，不读源码、仓库、配置，不运行本地脚本，不编辑 job/model JSON，不结束进程或清除未知保护。先确认用户允许当前会话正常建模；若界面有 Dashboard/警告或工具报告 unknown，保留现场并报告。

## 共同记录

先读取公开 capabilities compact、完整工具列表及会话状态，记录公开服务版本、部署是否陈旧、当前 Creo 信息及可确认的身份；接口未提供的信息写“无法确认”。每次提交保存完整输入、job_id/model_id，已接受任务只轮询 creo_get_job。逐例记录终态、revision、参数/体积、保存重载、原件保护及原始错误。测试使用独立名称和独立新模型，禁止复用用户旧异常模型注入故障。

## 场景

1. 能力输出：无参 capabilities 应沿用 0.4.2 compact 默认；遍历工具和 references 等 section，确认页有界、游标连续，非法/过期游标准确拒绝。旧 0.3.7 的无参大载荷问题不重开。
2. 圆角/倒角：新建 40×30×10 mm 长方体。用 inspect 得到真实边引用；独立 round(radius=2)、chamfer(distance=1) 各用新件。计划中分别使用 round 的 size/radius、chamfer 的 size/distance 别名，对照 native 尺寸及 compact/full 的 operations[].size。size 与别名同时出现、别名错配应准入拒绝且 revision/几何不变。
3. 无盘接管：由操作者准备独立 40×30×20 mm、从未保存的零件。prepare 返回 adopted=false、adopt_pending/revision0；轮询成功后由操作者关闭原件，再 apply 确认冻结副本。确认 adopted=true、ready/revision1，副本可继续 shell 去顶面、壁厚2，得到7152±0.01 mm³、revision2、保存重载通过。关闭原件不得重新复制来源；记录实际是否可完成，不能用其他成功场景替代。
4. 单位与只读枚举：操作者准备英寸独立件；接管拒绝中实际单位为 in，volume_mm3=null。枚举无盘、clean、dirty、钣金、装配及可用其他类型；未知属性应为 null 并有查询状态，同一快照分页无重复遗漏、不切窗。无需创建本环境无法提供的类型，列明未验证。
5. 真并发：仅在客户端能实际同时派发时，对独立新件的 prepare 或建模同时提交两次不同请求，保存开始时间与完整返回。持锁请求只允许一个获准，另一个应 busy 并有 blocking_*；忙请求不创建第二个作业。仅看到历史 busy 不能报告并发通过；无法并发就写未验证。
6. 历史恢复：仅选择操作者明确指定的已有异常模型，先做不带 live 的 inspect。缺失身份时读取 owners 的停止证据/拒绝原因；不要主动重启系统制造条件。只有动作实际 available、操作者明确选择后才 apply。分别对已准备好的四动作独立素材核对基线、候选、健康 live 或无基线归档条件；不为凑齐矩阵修改文件。成功后核对 revision、保存重载（abandon 除外）、幂等以及普通续作/已归档编辑拒绝。
7. 回调：操作者按已有一次性注册指引准备回调，公开状态须真实 ready。独立和计划入口用两个圆截面，R10/R6、间距25 mm、straight，期望体积4900π/3，容差max(0.01 mm³,体积×1e-6)，保存重载通过。升级/回退/重启及目录并存仅测试操作者已准备的真实阶段，记录手动启动/注册/重启次数；不自行写 config.pro、加载 DLL 或结束 Creo。
8. Creo 9 种子/筋/装配：仅在真实 Creo 9 环境测试。种子 list/validate 的 available 仅表示哈希有效，seed_build_version 无来源应为空，加载证据须绑定具体种子与原生 release。筋使用完整可复现的合法 L 形件和开放轮廓，覆盖 flip 与材料侧；装配从(-30,20,0)+Z30°位姿更新到三平面约束，提供实际引用和 side，核对矩阵、面位置/法向及重载。缺原始输入则提交最小完整输入和原始结果，不能直接宣布版本不支持。

快照改写、真实再生失败、恢复再中断等内部故障场景不通过本提示词人为制造；已有合法素材能观察到则记录，否则明确未验证。最终按“通过/失败/未验证”逐项报告，不据工具数量或本地开发测试判全通过。
