# FEAT-012：装配定位、源件更新与嵌套子装配

日期：2026-10-17 补全。类型：功能。优先级：P2。状态：待规划。目标版本：未排期。

来源：既有台账范围；新增[0.3.3 反馈补录](../validation/FEEDBACK-0.3.3-2026-10-17.md)报告 B 第 7、8 节。关联 BUG-036/041/045、FEAT-008/023/031。

## 目标与分期

保留既有装配定位补全、源件更新与嵌套子装配目标，按独立范围逐项设计与验收。本次只补明确的矩阵输入建议，不把整组能力视为本轮实施。

1. **直接姿态矩阵输入。** 评估 3×3 或 9 元素姿态输入，先确定唯一规范形状、存储顺序、行/列向量作用方向、局部到全局映射及平移语义，与 Euler rotation 互斥。校验有限值、正交性、行列式 +1 和数值容差；是否接受/如何处理小量非正交误差须明示，不静默转置、翻符号或接受反射/缩放。用于创建和更新放置，查询回显同一契约。
2. **源件快照与更新。** 报告通过 aliases 可追溯 source_model_id/source_revision，现有装配是源件快照。先说明源件修改不会自动联动，明确显式更新的身份、引用及回滚方案，再确定支持边界；本卡不承诺实时关联更新。
3. **定位和嵌套。** 约束求解和偏移缺陷继续由 BUG-036/041 核实；嵌套子装配按层级、引用变换、更新及分发另列最小用例。交付引用件打包归 FEAT-031，组件身份/输出体量归 FEAT-023。

报告 B 比对 18 实例时可用矩阵转置解释到约 `4.88e-8` 的元素残差；这不构成全局角度符号错误证据。BUG-045 继续负责现有 Euler 契约核对，本卡承接新增输入能力，避免重复建缺陷。

| 环境 / 用例 | 可判断的预期结果 |
| --- | --- |
| Windows / 输入 | 矩阵与 Euler 冲突、错误形状、NaN/无穷、反射/缩放/超容差非正交准确拒绝；旧 Euler 请求兼容；补回归与统一开发检查 |
