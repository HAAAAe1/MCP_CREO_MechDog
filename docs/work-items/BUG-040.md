# BUG-040：钣金第一壁后 body 清单出现无几何记录

日期：2026-10-16。类型：缺陷。优先级：P2。状态：待核实。目标版本：未排期。

来源：[Creo 9 / 0.3.0 报告](../validation/feedback-2026-10-16/2026-10-15_CREO_0.3.0_叶片种子加载失败与筋特征失败.md) 第四节第 6 项；[补录](../validation/FEEDBACK-2026-10-16.md)。关联 BUG-014、FEAT-006、FEAT-008。

钣金第一壁转换后 inspection 据报有两个 body：一个 bbox 正常，一个 id=-5778、无 bbox。报告称“幽灵 body”，但负 ID、空 bbox 本身不足以判记录无效；原生空/消耗/非活动 body、查询快照差异或计数错误均待核实。

范围与验收：空钣金→第一壁→后续折边，核对原生 body 枚举、状态、表面/材料归属及 job/inspect/list 的同一终态来源。真实材料 body 的计数/ID/bbox 与原生一致；允许的空记录须有明确状态和适用性，未知量保留 null，不能盲删所有负 ID。

对不可作为材料引用的记录返回准确原因和查询指引；合法 body 的后续操作、体积、保存重载及 revision 不受影响。仅显示列表正常不代替真实归属验证。

后续使用 Windows x64 / 本机 Creo 12.4 / 匹配 SDK、查询夹具与钣金原生回归；源 Creo 9 未复测。本次仅登记。
