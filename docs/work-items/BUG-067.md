# BUG-067：外部报告旋转特征创建返回 -1，需核对轮廓与 Creo 版本因素

日期：2026-10-18。类型：缺陷。优先级：P1。状态：已完成（2026-10-18，本机复现定性 + 报错修复；Creo 13 合法输入复测留外部条件）。目标版本：未排期。

来源：[0.3.7 / Creo 13 反馈补录](../validation/FEEDBACK-0.3.7-CREO13-2026-10-18.md)第 1 项；[原件](../validation/feedback-0.3.7-creo13-2026-10-18/report.md)问题 1。关联 [BUG-050](BUG-050.md)（coordinates 漂移）、[FEAT-008](FEAT-008.md)（sketch 引用契约）、[FEAT-006](FEAT-006.md)（原生错误诊断）。

## 现象与复现材料

报告环境为 Windows x64 / MCP 0.3.7 / stdio / WorkBuddy；Creo 版本自报 `13.4.1.0`、`release_numeric=45`、安装目录 `D:\PTC\CREO13`。版本与 release 的对应关系、匹配 SDK、受测源码提交及指纹尚未独立确认，原样保留，不能据此认定 Creo 13 已受支持或不兼容。

1. 新建 `sphere_r10` 成功；XY 草图 `sphere_profile` 为半径 10、0°→180° 圆弧、直线 `[-10,0]→[10,0]` 和中心线 `[0,-15]→[0,15]`，`dimensioning="autodim"`，草图创建成功。随后标签引用、360°、add 旋转失败，报 `Toolkit call ProFeatureWithoptionsCreate failed with code -1 during execute_revolve`；job `5f30c76ae9284b8da0a8be6f9f55c240`。
2. 计划入口：XZ 平面、31 点闭合折线近似半径 5 的半圆、竖直中心线、autodim，草图成功、旋转同码失败；job `efb710634ba14f0281d0ac7d9090cbed`，报告模型名 `prt001`。完整点列与轴位置未附。
3. 报告称回滚 `rollback_succeeded=true`、模型可继续操作；同会话种子放样和保存重载成功。尚缺原始请求、完整终态、model_id、原生日志及保存重载文件，当前未在本机复现。

`2dea38904e644da7819bda098a424ab6` 在原件同时出现在旋转失败及整数引用说明中，具体请求归属待核对；不得把 `Unknown feature label: 40` 算成已进入原生旋转的失败。

## 待验证原因与范围

- 先核对几何合法性。按通常二维坐标解释，尝试 A 的上半圆区域跨越竖直旋转轴，可能形成重叠/自交旋转实体；尝试 B 是否同样跨轴未知。“多种轮廓失败”尚不能证明与画法无关，更不能直接证明元素树版本差异。
- 初始目标为直径 10 mm，但尝试 A 半径为 10 mm、B 为 5 mm，复现时分开记录，不混用体积预期。
- 取得完整请求后，保留原输入作失败对照，再准备区域完全位于轴一侧的合法半圆及矩形。记录实际选用的轴、原生创建诊断、失败阶段和模型保护结果。
- 仅在合法输入仍失败时，调查旋转元素树、外部草图/轴引用和 SDK 差异。元素树 dump/对照是开发者候选方法，不是本次已执行步骤，也不要求 WorkBuddy 读取源码。
- 覆盖独立 `creo_revolve` 和计划 revolve 的合法增料、受影响既有旋转/切除回归；整数引用说明归 FEAT-008，不混同于创建失败。近似放样不能代替精确旋转验收。

## 实现与证据

2026-10-18 当日完成复现、定性与修复，完整证据见 [复现与修复记录](../validation/BUG-067-repro-2026-10-18.md)。要点：

- 本机 Creo 12.4 / 匹配 SDK 经公开 MCP 接口复放：两例报告输入（r=10 上半圆+竖直轴；31 点折线半圆+竖直轴）**同码复现** `ProFeatureWithoptionsCreate=-1`、回滚成功；合法画法（轴与直径边界重合的 r=5 半圆）一次成功，体积 523.5987755983589 mm³ = 500π/3，半径 5→6 编辑后体积 288π 精确。`examples/turned_part.json` 回归通过。
- 定性：两例为非法跨轴旋转截面，**非 Creo 13 元素树不兼容**；"与轮廓画法无关"不成立。遗留产品缺陷是"拒绝但不解释"。
- 修复：`native/geometry.cpp` 元素级错误累积可回传；`native/generic.cpp` 旋转/拉伸创建失败时带上下文重抛（跨轴/中心线/闭合提示 + 草图标签 + 元素错误）。拒绝、回滚与 revision 保护行为不变；不做跨轴预检。
- 回归：`tools/dev_check.py` 通过；`tools/test_general.py` `GENERAL_CORE_SUCCESS=1`。
- `2dea389…` 归属：整数引用报错发生在元素树构建之前，与旋转创建失败为两条路径，归 FEAT-008。
- 未测：Creo 13 合法输入复测（外部条件具备后按"外部报告环境"行执行）；WorkBuddy 黑盒复核。
