## 缺口

恒定半径 `round` 在两端收敛于近切点的边上无解（滚动球半径退化为零宽）：

- 复现 A（10 条边，R2）：job `dbaea9c036a54c1694dbfe12ace72166` → `execute_round` 失败（Regeneration produced a failed, suppressed or incomplete feature），自动回滚；
- 复现 B（单边 edge 138，R2）：job `bc9575c08b914a1495aa07f7501c25ef` → 同样失败。

场景为爪侧面（平面）与 R33 球面交线的爪谷圆角——任务书"胜负手"之一，当前只能留锐边。这不是缺陷（几何上恒定半径确实无解），是能力缺口。

## 候选能力（反馈建议）

1. `variable_radius` / 半径表；
2. `stop_at_reference`、`extend_to_surface`（圆角延伸到相邻曲面而非在切点收尾）；
3. 失败错误携带冲突边 id 与最小可行半径估计（诊断部分归 FEAT-006，联动实现）。

## 范围

- 与 FEAT-039 的曲面链路验收用例（可乐瓶任务书第 6 步 R2/R1）联动，但独立排期。
