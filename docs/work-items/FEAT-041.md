# FEAT-041：交付与预览体验（输出目录、视角可选）

日期：2026-10-18。类型：功能。优先级：P3。状态：待规划。目标版本：未排期。

来源：外部 0.3.5 曲面链路反馈 §3 第 6/7 条（Creo 10.0.0.0），见[原件](../validation/feedback-0.3.5-surface-2026-10-18/report.md)。接口体验小改进归拢项。

## 缺口

1. `creo_new_part` 无输出目录参数：模型固定落 `models/<model_id>/output/*.prt.N`，交付需手工复制。建议增加 `output_dir`。
2. 预览固定 3/4 视角不可指定：验收需要仰视/正视时只能自行导出 STL 渲染。建议 `export(format:"jpeg", view:"bottom"|"front"|"top", orthographic:true)`。

## 范围

- 仅新增可选参数与视角渲染选项，默认行为不变；输出目录不引入仓库外任意写路径（校验存在于允许清单或提示配置）。
- 与 FEAT-039 的验收用例联动（瓶底仰视图可直接复用 view:"bottom"）。

## 验收标准

| 环境 / 用例 | 命令或操作 | 可判断的预期结果 |
| --- | --- | --- |
| Windows / Python | schema/单测 | 新参数可选、默认行为与旧请求完全一致 |
