# FEAT-032：闭环路径的曲线阵列与实例站位契约

日期：2026-10-16。类型：功能。优先级：P2。状态：待规划。目标版本：未排期。

来源：[履带反馈](../validation/TRACK-FEEDBACK-2026-10-16.md)第四节与 rev2 的 PAT01～03。关联 FEAT-011（扫掠轨迹扩展）、BUG-035（现有尺寸阵列）、BUG-049、DEV-031；不重复归入轴阵列或尺寸阵列。

## 目标与范围

评估原生沿曲线阵列：由可明确引用的路径和种子特征，按弧长布置、随切向定向，并定义首站相位、方向、闭环接缝、计数是否含种子、跳站索引、组成员、资源/引用及 revision。报告建议的 `creo_curve_pattern` 与 `PRO_PAT_CURVE` 仅为方案线索，须在本机匹配 SDK 核实可行性，当前不宣称已有接口。

先做单种子/无跳站/平面路径最小闭环，再处理履带的多特征种子和跳站；变截面扫掠、任意空间曲线姿态、阵列嵌套不自动纳入首批。不能把多轮廓合并后的一次拉伸称作原生曲线阵列，替代方案须准确声明特征类型和受限分支。

## 设计与验收

| 场景 | 可判断的预期结果 |
| --- | --- |
| 直线/圆弧/非圆平面闭环 | 路径引用唯一、站位弧长和切向正确，原生实例和几何与独立站位计算一致；闭环不重复末站 |
| 计数与相位 | count 明确含种子；正/反方向、偏移相位与两种路径起点对照可复核。非圆路径改变相位可能改变几何，不宣称任意相位等价 |
| 履带 PAT01 | 冻结精确路径后 63 站，步距取实际周长/63；P03/P04 同站、方向正确，切口和窗口数量分别 63，单材料实体及保存重载正确 |
| 跳站与多特征种子 | 跳站索引基准明确、无效/重复索引准确拒绝；PAT02/03 的 15 站各跳 1 和 P06 两站按冻结输入核验，不因总数 30 就认定站位等价 |
| 编辑与依赖 | 修改种子/路径后再生符合明确契约，已有特征身份与引用有效；支持路径可保存重载，revision +1 |
| 失败与保护 | 不支持路径、模糊引用、失效种子、材料退化及过期 revision 准确拒绝或回滚，文件/revision 不误推进，后续合法建模可用 |

Windows x64 / Creo 12.4 / 匹配 SDK：方案先登记原生可行性，再做统一检查、SDK 构建与阵列/参数/保存重载回归。若新增公开工具，登记 capabilities.py 并同步示例、接口说明与版本规则。WorkBuddy 只调用正式公开工具核验真实参数、几何、revision 和错误；未实现前不提供可运行的假工具提示词。
