# BUG-068：auto 草图圆弧端点 coincident 约束返回 -2

日期：2026-10-18。类型：缺陷。优先级：P1。状态：待复现。目标版本：未排期。

来源：[0.3.7 / Creo 13 反馈补录](../validation/FEEDBACK-0.3.7-CREO13-2026-10-18.md)第 3 项；[原件](../validation/feedback-0.3.7-creo13-2026-10-18/report.md)问题 3。关联 [BUG-037](BUG-037.md)（显式尺寸引用）、[BUG-050](BUG-050.md)（coordinates）、[BUG-051](BUG-051.md)（autodim）、[FEAT-006](FEAT-006.md)（诊断）。

## 现象与待验证根因

外部自报 Windows x64 / Creo 13.4.1.0（release_numeric=45）/ MCP 0.3.7 / WorkBuddy：`dimensioning="auto"` 下给圆弧端点与直线端点添加 `coincident` 约束，`ProSectionEntityGetSelected(...) failed with code -2 during execute_sketch`，job `7ee24b858b9f4ee588cc0981a5a31fb1`。完整实体名、端点选择、约束数组、model_id 和原生约束诊断未附，需补原始请求。

“Intent Manager 开启后按名字解析失败”仅为报告推测。也须核对实体别名、whole/start/end 引用、重合点与重复约束、图元展开和选择时机。与 BUG-037 的 `ProSecdimCreate=-2`、BUG-051 的 autodim 求解失败接口和模式不同，先独立建卡；定位后若证实同因，再交叉关联，不提前合并结论。

## 范围

冻结最小圆弧+直线输入，分别测试 arc.start/arc.end 与 line.start/line.end 的合法非退化引用，比较无约束、单个/两个端点重合、纯直线重合以及 autodim 对照。覆盖独立草图和计划入口；保留原生约束及可编辑尺寸，不静默删除约束或切换模式。非法名称/端点应提供可判断的错误，不能仅重复 Toolkit -2。
