# BUG-006：引用类型与工具参数契约不明确

日期：2026-10-14。类型：缺陷。优先级：P1。状态：开发中。目标版本：未排期。

来源：用户提供的 `MCP_CREO_MechDog_dev_全量工具测试报告.md` 第 6 节 P0-1、第 7 节 N1。该编号是报告内编号，本仓库使用固定 ID BUG-006。基于 DEV-002 第一批分支，新辅助模块放入 src/creo_mechdog，版本保持 0.2.6。

## 现象与复现

报告中 axis_pattern.axis 使用 `{"kind":"datum_feature","label":"t82_da1"}` 时校验报 `Pattern requires an axis reference`，改为 `{"kind":"axis","id":83}` 后任务成功。源码复现同样拒绝前一种输入；现有 `{"kind":"datum_axis_feature","label":"t82_da1"}` 实际已可通过，不能由报告推断接口只支持几何 id。

目前通用 datum_feature 在原生 resolve 中代表基准平面，datum_axis_feature 才解析轴。能力说明只给泛称 datum_label，缺少各参数的几何类型和结构层次。倒圆/倒角 references 是集合对象；草图 plane 是包含支撑引用与坐标的对象；钣金 flange.edge 是单条裸边引用。这些结构未清楚区分，造成试错。

## 范围与验收

1. axis_pattern 接受裸几何轴、显式轴特征标签，并按轴参数上下文兼容报告中的 datum_feature 标签，规范化为 datum_axis_feature 后交给现有原生执行器。非法几何类型、缺少/非法 id 或 label 保持拒绝，并返回完整可操作示例。未经证据支持的任意包装不新增为通用接口。
2. 在 MCP 工具 schema/描述和 capabilities.references 中明确单引用、数组、倒圆/倒角集合、草图支撑包装及工具特定种类。保留原 capability 键、有效旧输入、revision/回滚与原生引用解析逻辑。
3. 回归报告的精确输入、等价规范化、有效旧输入、错误提示与非法类型；检查高层工具和 execute_plan 共用规范化，非法输入在任务入队前拒绝。真实 stdio MCP 核对工具 schema 和 capability 示例。
4. 执行 Windows 开发检查与适用源码包验证；本机 Creo 12 的实际轴阵列（几何、参数、保存重载）能取得就记录，否则明确未验证，Creo 10 由其他机器协助者验证。未改 C++ 不代表实际建模自动通过。
