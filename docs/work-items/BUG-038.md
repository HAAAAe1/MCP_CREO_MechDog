# BUG-038：布尔模型参数被存成实数

日期：2026-10-16。类型：缺陷。优先级：P2。状态：已完成。目标版本：未排期。

**2026-10-16 结论**：[0.3.2 报告 B](../validation/FEEDBACK-0.3.2.md) 在 Creo Parametric 9.0.0.0 / MCP 0.3.2 上实测 `true` 已正确存为 `BOOLEAN(53)=True`（0.3.0 受测时为 REAL(52)=1）。按用户 2026-10-16 决定采信该外部结论转已完成并移入[归档](../BACKLOG_COMPLETED.md)：本仓库无对应修复提交可核实，未在本机复验布尔映射与保存重载；本机复现失败须重开本 ID。下方原来源、范围与未测边界保留。

来源：[Creo 9 / 0.3.0 报告](../validation/feedback-2026-10-16/2026-10-15_CREO_0.3.0_叶片种子加载失败与筋特征失败.md) 第四节第 4 项；[补录](../validation/FEEDBACK-2026-10-16.md)。

`set_parameters({"WB_OK":true})` 据报存为 REAL（type=52）值 1，与布尔支持声明不符。Python bool 与 int 的类型分支、序列化和原生参数映射均待核实，不能只凭报告锁定根因。

范围包含新增/更新参数及独立工具/计划。true/false 应可查询为原生逻辑类型并在保存重载后保持；0/1、浮点和字符串仍按已声明类型处理，不能用值相等替代类型正确。已有参数类型不能合法转换时须明确拒绝，参数、revision 与检查点保持，保留既有数值/文本兼容。

后续验收：Windows x64 / Python 类型映射与校验回归、适用开发检查；本机 Creo 12.4 / 匹配 SDK 原生参数查询、更新及保存重载 true。源报告为 Creo 9 / 0.3.0，未独立复测；本次仅登记。
