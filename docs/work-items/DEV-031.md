# DEV-031：履带纯文本输入规范化与分阶段综合回归

日期：2026-10-16。类型：工程与验证。优先级：P2。状态：待规划。目标版本：未排期。

来源：[履带 rev2 原件](../validation/track-feedback-2026-10-16/track-modeling-rev2.txt)、[外部 Creo 10 / 0.3.2 报告](../validation/track-feedback-2026-10-16/creo10-0.3.2-track-feedback.md)及[映射/输入核对](../validation/TRACK-FEEDBACK-2026-10-16.md)。关联 BUG-001、BUG-040、BUG-049～053、FEAT-008、FEAT-032、FEAT-033。

## 目标与边界

将同一真实案例拆为可定位的最小回归，再做完整闭环履带，输入仅来自纯文本，使用 Creo 原生参数特征；不能导入现成实体、复制源 CAD 或改名当重建。交付几何外形/装配占位近似，不承诺制造公差、材料工艺或无几何证据的帘线结构。

两份原件保持原字节，另外形成带来源行号的规范化参数、坐标和验收表。它不是当前已通过样例；源 SOLIDWORKS 验证、另一份 SOLIDWORKS 近似重建、外部 Creo 成果及本机将来的测试分别记录，不相互冒充。

## 实施门槛与分阶段输入

1. **冻结输入。** 明确 213.3 是英寸标称节线总长，非模型 X 长度；精确路径由高精度几何重新核对，不能同时要求三位小数端点、给定半径/角度和严格 G1 无误差。记录端点闭合误差、半径/方向和容差，禁止静默吸附或放宽自检。原文 PAT03 的 180.8217 与等效规则的 90.4108 相位冲突、OP04 的种子引用错误，以及“不影响几何”的断言必须先澄清或以独立计算冻结可审查选择。
2. **最小件。** 单一精确线弧路径、20 点截面、一个切口和一个窗口；分别验证 coordinates/autodim、sweep 及 active material body，记录阶段检查点。
3. **63 站。** 精确站距用确认路径周长/63，P03 与 P04 同站；每个批次先验相交，不把奇偶分组或固定每组三个当通用保证。曲线阵列未实现时只记录替代原生做法，不伪称原生 Pattern。
4. **30 站/90 块。** 甲/乙站、跳站与端部补站按冻结相位处理，C 框 30、I 条 60；拔模方向/自由高度/埋入深度/根部槽闭合分别验证，不因体积接近而省掉 25°/27° 拔模。
5. **性能与恢复。** 记录从小件到完整件的阶段耗时、规模和所用预算；异常测试仅在隔离副本注入，原有未知作业不重交。失败恢复门槛来自 BUG-001/FEAT-018，性能与预算来自 BUG-053/FEAT-033。

输入存在实质歧义时停在冻结阶段并提出具体选择，不能借“允许近似”绕过数量、方向、体积或拔模门槛。

## 实现与证据

本次只有来源、任务卡和范围核对，未生成任何 CAD 模型或测试脚本。规范化参数与最终可执行回归入口在冻结阶段登记；每次证据记录真实源码身份、输入摘要、job/model、revision、几何、保存重载、预算及未测范围。完成后同步台账与能力边界，不覆盖原件或历史报告。
