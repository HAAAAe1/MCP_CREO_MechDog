# BUG-014：inspection计数与恢复状态不准确

类型：缺陷；优先级：P1；状态：验收中；目标版本：未排期。

来源：台账原全量报告及2026-10-14尺寸编辑报告。compact将缺失数组计算成0；失败结果可能是失败中间状态而非恢复状态，板件缺少几何详情。

范围：真实零/未知null、计数与详情一致、空件has_solid、实际回滚inspection及来源；板件只补可核实计数，不增加模型注册。成功、失败恢复、恢复失败、未知状态单元回归和实机；环境和命令见[联合任务](P1-MODELING-REPAIR.md)。

## 本轮交付

恢复状态与失败中间状态分离；无检查点失败返回null；空件无实体；板件分类计数真实且缺失字段未知。未注入回滚失败/未知结果。

开发阶段记录：[独立证据](../validation/BUG-014.md)、[联合证据](../validation/P1-MODELING-REPAIR.md)。当时尚待 WorkBuddy 最终验收，后续进展见下文；原环境输入未齐的事实保留，不作为独立复测要求。
