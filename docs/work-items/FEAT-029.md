本项围绕 `build/blend_callback.protk.dat` 的升级注册生命周期，并关联 FEAT-008 中的回调 loaded/协议匹配/未知状态预检；FEAT-008 其余能力契约事项保持原排期。提升优先级不代表重新注册负担已实际复现，稳定路径仍是候选方案，实施前先核实加载身份、升级行为与验收范围。

## 问题、范围与验收

报告观察回调副本目录和命令含 DLL SHA256，0.3.0→0.3.1 的 DLL 改变后注册路径改变，推测需反复注册。反馈方从未成功注册过，升级后失效、同名冲突和重新注册成本尚未实测，不能登记成已确认故障。

范围：评估稳定注册入口、不可变 DLL/多版本身份、已加载文件占用与兼容协议的升级流程，或保留当前副本策略并提供准确升级提示。稳定 current 路径仅为候选，protocol 相同也不能直接证明二进制/命令兼容或允许覆盖已加载 DLL。

验收须覆盖首次注册、原模块仍加载时升级、DLL 改变/未改变、协议变化、回滚和并存安装；可核实地区分当前产物、实际会话模块与未知状态，给具体下一步且旧模型/会话可用。最终方案需确认几何、原生放样、revision、保存重载和失败恢复。测试前置由发起者按正式流程完成注册/安全确认；建模和查询不自动加载 DLL、不修改 Creo 策略。

后续开发按 Windows x64 / 本机 Creo 12.4 / 匹配 SDK 取证，原 Windows 10 / Creo 10 / 0.3.1 反馈保留。实际 GUI 注册由有条件的测试发起者执行，未执行则记未验证；不因缺少旧版独立验收阻塞其他本机工作。本次仅提出候选与验收边界，未定实现或开展测试。
