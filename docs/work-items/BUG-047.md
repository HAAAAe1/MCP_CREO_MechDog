# BUG-047：钣金折边 flip 未表现为可控方向变化

日期：2026-10-16。类型：缺陷。优先级：P1。状态：待核实。目标版本：未排期。

来源：[0.3.1 钣金配电箱报告](../validation/feedback-2026-10-16/2026-10-16_CREO_0.3.1_钣金工具链增料失效与折边方向不可控等10项缺陷.md) S2；[补录](../validation/FEEDBACK-2026-10-16.md)。关联 FEAT-008、FEAT-014。

底板下缘 z=0、h80、flip=false 向 +Z；上缘 z=1、h80、false 向 -Z，上缘 h79、true 据报仍向 -Z（jobs `cb07084422874caabfa030cbb485e490` / `a4ca1713bf2e4cb39cf3c860056906a7`）。壁顶内/外缘再折边均向外，x91.5→111.5（`cb5b16b3a1da41ea915f15153126814e` / `0268e5da99c847dd91321442ca28b560`）。

需核实 flip 的公开语义是弯折方向还是材料侧，并补同边、同高、同半径、仅 flip 变化的对照；原实验同时改 h80→79，不能据此确认参数被忽略。边 ID 随模型变化，复现须 inspection 获取真实边。

范围与验收：第一道上/下缘及第二道壁顶内/外缘，独立工具/计划。声明可控的方向或材料侧须与几何一致，明确参考边/驱动面/正负方向，必要时回显方向与 bbox；向内 20 mm 的合法正例不能默认为向外。原生折边、半径/角度/高度、体积和保存重载 true、revision 正确；无效边/角部冲突拒绝后恢复可用。四壁释放能力另归 FEAT-014，不用该限制掩盖独立 flip 问题。

后续使用 Windows x64 / 本机 Creo 12.4 / 匹配 SDK、适用检查与折边方向原生回归；来源具体 Creo/OS/构建无法确认。本次仅登记。
