# BUG-070：会话查询返回的当前模型名称异常

日期：2026-10-18。类型：缺陷。优先级：P2。状态：待复现。目标版本：未排期。

来源：[0.3.7 / Creo 13 反馈补录](../validation/FEEDBACK-0.3.7-CREO13-2026-10-18.md)第 4b 项；[原件](../validation/feedback-0.3.7-creo13-2026-10-18/report.md)问题 4。关联 [BUG-069](BUG-069.md)（创建名校验）、[FEAT-042](FEAT-042.md)（接管身份核对）。

## 现象与待验证原因

外部自报 Windows x64 / Creo 13.4.1.0（release_numeric=45）/ MCP 0.3.7 / WorkBuddy：Creo 当前手动打开 `001.prt`，`creo_session_status.current_model` 显示为 `▩0010001`。未附完整响应、界面截图或原始字符串字节，不能据此确定错误发生在 Toolkit 字符串读取、编码转换、缓冲区处理、JSON 序列化还是客户端显示。

## 范围

冻结同一模型的 Creo 可见名称、原生读取结果、服务输出及客户端呈现，检查名称长度、终止符和 Unicode 转换；先核对实际字段路径及是否为陈旧状态。查询保持只读，不因补全名称而登记、保存、接管或擦除用户模型。不能仅移除异常字符来掩盖错误身份。

| 环境 / 用例 | 命令或操作 | 可判断的预期结果 |
