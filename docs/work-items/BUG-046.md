# BUG-046：钣金件上的单区域重叠拉伸增料失败

日期：2026-10-16。类型：缺陷。优先级：P1。状态：待复现。目标版本：未排期。

来源：[0.3.1 钣金配电箱报告](../validation/feedback-2026-10-16/2026-10-16_CREO_0.3.1_钣金工具链增料失效与折边方向不可控等10项缺陷.md) S1；[补录](../validation/FEEDBACK-2026-10-16.md)。关联 FEAT-008、FEAT-006，与 BUG-042/043 分别验收。

模型 `56d4cdae6b7242929d7180949905ef1a` 为 sheetmetal、1 body。与底板有重叠的 10×10×5 单环 add 两次 -1（jobs `9256690b7e13417b9bc9c90e45630fe8` / `4b0c0d9b738a4373ba292afe4a65034c`），Ø10 through_all cut 成功（`95940e69a01240cab11fb3e9850aa102`），体积减约 78.54。报告据此称所有增料不可用，但旋转等入口未有此最小对照，不扩判。

范围：先核实钣金材料模型是否允许该实体增料形式、原生 API/元素树与公开能力一致性；补完整单环、父体、深度/方向/目标体。合法受支持增料应产生正确材料和原生特征，保留钣金身份及后续展开/折回能力，保存重载 true、revision 正确。若该组合不支持，提交前或失败时给明确边界与可行工具指引，不以裸 -1 暗示任意几何均可。

以普通实体同截面 add、钣金 cut 为对照；失败保留检查点/revision，后续 cut/钣金操作可用。不能用普通实体替代件冒充钣金成功。

来源具体 Creo/OS/构建无法确认；后续 Windows x64 / 本机 Creo 12.4 / 匹配 SDK、适用检查及钣金/拉伸实机回归。本次未复现或修复。
