日期：2026-10-18。类型：工程整理（缺陷修复执行卡）。优先级：P2。状态：待开发。目标版本：未排期。

来源：[BUG-019](BUG-019.md)（已确认待开发：参数映射已从代码核实）。执行卡组织开发与验收，不改变缺陷卡的结论与边界。

## 目标

让 `creo_round` / `creo_chamfer`（独立工具，输入 `radius` / `distance`）与 `execute_plan` 的 `RoundOp.size` 三入口的字段、映射与返回可对照、可自查：调用方不再需要猜"我传的 radius 变成了什么"。不统一改名，不把名称差异认定为原生建模失败。
