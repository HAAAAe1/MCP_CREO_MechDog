# BUG-071：接管预检失败残留无令牌登记

日期：2026-10-18。类型：缺陷。优先级：P1。状态：已完成（开发分支）。目标版本：未排期。

来源：现有模型无法纳管反馈；关联 FEAT-042。

## 现象与复现

0.4.0 的 adoption.inspect 在原生预检返回后，来源哈希、冲突扫描、令牌写入位于清理边界外。隔离原生夹具返回空 origin，Python 抛 PermissionError 后残留一个 adopt_pending/model.json，证据令牌数量为零。复现未连接 Creo。

## 范围与验收

完整覆盖预检、来源校验及证据发布的收尾；只删除本次创建的登记目录。确定失败不留半登记，已派发且结果未知的写入仍保留保护。补来源读取、冲突扫描和证据写入失败回归，运行统一开发检查。无盘 inspect 给出 prepare 指引，不对空路径调用文件哈希。

## 实现与证据

本轮在 codex/feat-042-adoption-completion 实施。登记改为在来源/哈希/冲突/令牌成功后最后发布，全部步骤在同一锁与清理边界内；已确认失败不留下可见半登记。空origin返回prepare指引，不哈希当前目录。哈希、冲突扫描、令牌写入故障回归及完整403项单元/统一开发检查通过。独立快照写入派发后的未知结果保护不变。证据见[本轮记录](../validation/ADOPTION-COMPLETION-2026-10-18.md)。FEAT-042于2026-10-19取得[WorkBuddy无盘续作主链证据](../validation/ADOPTION-WorkBuddy-2026-10-19.md)，剩余矩阵继续验收；该黑盒成功不替代本卡内部故障收尾的开发证据。
