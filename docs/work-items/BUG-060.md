# BUG-060：sheetmetal_unbend 的 fixed_surface 不接受 datum_plane 引用

日期：2026-10-18。类型：缺陷。优先级：P2。状态：待核实。目标版本：未排期。

来源：外部 0.3.5 钣金第四轮回归反馈的 S6（本轮未复测，沿用 0.3.3 实测），见[原件](../validation/FEEDBACK-0.3.5-SHEETMETAL-2026-10-18.md)。关联 [FEAT-008](FEAT-008.md)（fixed_surface 引用格式说明）。

## 报告现象（0.3.3 实测，0.3.5 未复测）

`sheetmetal_unbend` 的 `fixed_surface` 传 datum_plane 引用时报错失败；0.3.5 轮反馈未复测（S1/S3 同代码路径未变的推断不适用于本项，需独立验证）。

## 待核对

- fixed_surface 的 schema 与原生实现实际接受哪些引用类型（surface id / datum_plane label / 其他）；
- 若确实只接受面引用，报错是否说明应传 `{kind:'surface',id:N}` 及如何查询可用面；反馈建议二选一：支持 datum_plane，或给出可操作的报错提示；
- 与 FEAT-008 的字典平面/引用格式说明统一处理，不单独放宽校验。

## 范围

仅 unbend/flat_pattern/bend_back 家族的 fixed_surface 引用解析与报错；不改变固定面语义。

## 验收标准

| 环境 / 用例 | 命令或操作 | 可判断的预期结果 |
| --- | --- | --- |
| Windows / Python | schema 与离线校验核对 | 明确列出接受与拒绝的引用类型，与文档一致 |
| 实机（待复测） | datum_plane 与 surface 引用对照 | 支持的类型成功展开并重载；不支持的类型给出可操作报错 |

## 实现与证据

2026-10-18 仅登记。未复现、未修改实现。原始证据见反馈原件 S6 行；0.3.3 实测记录见该轮反馈原件。
