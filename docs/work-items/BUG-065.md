# BUG-065：datum_axis 两平面求交退化为法向，且轴不可观测

日期：2026-10-18。类型：缺陷。优先级：P2。状态：待复现。目标版本：未排期。

来源：外部 0.3.5 能力边界反馈 P5（Creo 10.0.0.0 / release 42），见[原件](../validation/FEEDBACK-0.3.5-CAPABILITY-2026-10-18.md)。关联 [BUG-063](BUG-063.md)（非原点轴阵列错误，本项为其根因之一）。

## 报告现象（外部实机，由阵列结果反推）

`creo_datum_axis(references=[{kind:'datum_plane',id:70},{kind:'datum_plane',axis:'x'}])`（y=−0.504 平面 ∩ x=0 平面，交线应为 Z 向直线）返回 succeeded，但后续阵列几何表明**生成的轴与平面 70 的法向 +Y 一致**（实例被转到厚度外、几乎不切料的量化特征只有横向轴会造成）。疑似求交分支退化为"取第一个引用平面的法向"。

同时 `creo_datum_axis` **无任何返回信息**（不含 origin/direction），`creo_inspect_model` 也无 axes 段——阵列前无法校验轴是否正确，外部称之为本次排障最耗时的一点。

## 待核对与修复方向

1. 本机复现两平面求交：构造两个已知平面 → 建轴 → 由阵列或截面反推轴方向，确认退化分支。
2. 修求交实现（ProDatumaxisCreate 的两平面约束路径）。
3. 返回 `{origin, direction}`；`creo_inspect_model` 增加 axes 段（或 datum_axes section）。

## 验收标准

| 环境 / 用例 | 命令或操作 | 可判断的预期结果 |
| --- | --- | --- |
| 本机 Creo 12.4 | 两正交/斜交平面求交建轴 | 轴与几何交线一致（origin/direction 断言）；返回与 inspect 可见 |
| 回归 | 柱面取轴、单平面法向轴既有路径 | 行为不变 |
