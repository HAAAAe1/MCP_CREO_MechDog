# BUG-042：多个分离区域截面的拉伸增料失败

日期：2026-10-16。类型：缺陷。优先级：P1。状态：待核实。目标版本：未排期。

来源：[0.3.1 实体配电箱报告](../validation/feedback-2026-10-16/2026-10-16_CREO_0.3.1_多区域截面拉伸与共面合并等10项缺陷.md) P1；[补录](../validation/FEEDBACK-2026-10-16.md)。关联 BUG-043、FEAT-008、FEAT-006。

## 现象与待验证原因

2/6 个互不相邻闭合环 add 报 `ProFeatureWithoptionsCreate=-1`，jobs `6c7506ce1ff64c10ad089390f955e19e` / `41392120ece64a5e9bec671bae1ac9ad`；同区域拆单环、嵌套双环 add 及 6 环 cut（`8c5fe7850ad54a8b86bfc66c364905d6`）据报成功。模型 `fb8c5b7fc3604dd1a3756071678c9397` / `3eca200ecc254cd3a0062b921dd4379d`。

需补完整草图、父体/目标 body、方向、深度和 new_body 输入。报告“add 仅支持单区域”是范围推断；与父体接触、分离体策略或截面合法性尚未独立排除，revolve 没有此项实测。

## 范围与验收

分别测空件、多区域均与同一父体重叠、仅部分接触、多体模式，并以单环/嵌套环/cut 对照；共面问题由 BUG-043 独立控制。支持的多区域路径需原生拉伸有效、体积/bbox/body 归属正确、保存重载 true、revision 正确。明确不支持的组合给可识别原因、拆分/目标体指引并保持检查点；不能用笼统 -1 代替限制说明。

来源只给服务 0.3.1，具体 Creo/OS/构建身份无法确认。后续使用 Windows x64 / 本机 Creo 12.4 / 匹配 SDK、适用开发检查及拉伸原生回归，其他环境按反馈补录。本次未复现或修复，不直接把所有多区域列为已确认限制。
