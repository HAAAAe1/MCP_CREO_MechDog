# DEV-019：原生构建失败诊断改进（C2065 模式识别 + 错误摘要）

日期：2026-10-15；更新：2026-10-16。类型：工程整理。优先级：P2。状态：已完成。目标版本：未排期。统一批次：[DEV-028](DEV-028.md)。

来源：[第三方用户 0.3.0 Creo 9 SDK 编译失败反馈](../validation/2026-10-15_CREO_0.3.0_旧版ToolkitSDK原生编译失败.md)（"失败形态是裸的 C2065，用户无法直观判断 SDK 版本不匹配"；"`INSTALL_INCOMPLETE` 只给出日志路径"）。关联 [BUG-033](BUG-033.md)。

## 目标

降低原生编译失败的用户排查成本。BUG-033 探测宏修复主路径后，PROBES 白名单只覆盖已知常量；未来出现新的版本敏感常量漏网时，仍会以裸 C2065 形式失败，本条目为该场景兜底。

## 范围

包含：

1. `bridge.py build` / setup 失败路径解析 `build/build.log`：命中 `error C2065` 且未声明标识符以 `PRO_` 开头时，在错误消息中追加方向性提示（"常量 <名称> 来自较新的 Creo Toolkit SDK，本机 SDK 版本可能低于所需"）；
2. 同一失败路径无条件附加 build.log 末尾 error 行摘要（截取有限行数，如 ≤15 行，仅保留 error 级别行）。

不包含：常量名→所需 Creo 版本数据库（不做，仅提示方向）；C4819 等无害警告的转译；MCP 服务阶段（server.py）的输出改动——仅影响 setup/bridge 阶段的异常消息/stderr，不触碰"服务 stdout 仅用于 MCP 协议消息"的约定。

## 验收标准

| 环境 / 用例 | 命令或操作 | 可判断的预期结果 |
| --- | --- | --- |
| Windows / 单元测试 | 构造含 `error C2065: "PRO_XXX": 未声明的标识符` 的伪 build.log，触发失败路径 | 错误消息包含 SDK 版本方向提示及摘要行 |
| Windows / 单元测试 | 构造仅含普通链接错误的伪 build.log | 仅附加摘要，不出现 SDK 版本误导读入 |
| Windows / Python | `tools/dev_check.py` | 无新增语言问题，全部单测通过 |

实机失败场景依赖真实旧版 SDK，本机无法构造；以夹具单测为准，实机证据收到新反馈后补录。原生建模范围不适用（本条目不改建模行为），写明原因即可。

## 实现与证据

2026-10-16 实现：新增包内 `src/creo_mechdog/build_support.py` 的纯函数 diagnose_build_failure，bridge.py 在构建和前置自检失败时统一追加诊断。失败时最多读取日志末尾 128 KiB，丢弃不完整首行，仅保留末尾最多 15 条 error / fatal error；C2065 且含 PRO_ 名称才加 SDK 版本方向提示，不声明具体最低版本。不含 error 行或日志不可读时也保留明确摘要，原始日志不改写。不改变服务协议输出。

Windows / Python 3.12.14 的 C2065、普通标识符、普通链接错误、警告过滤、15 行上限、大日志和不可读日志夹具通过；bridge.py 失败集成夹具确认错误真正进入异常。受测提交基点 `b6c7daff61bc9f2ef288b5984f823a9945ab8710`，dirty=true，版本 0.3.1。源码指纹、完整检查与环境见 [本批验证](../validation/DEV-028.md) 及其 JSON；本机无旧 SDK，真实旧 SDK 编译失败提示未实机验证，原生回归由 DEV-028 汇总。

## 2026-10-16：0.3.3 成功日志与警告展示反馈

[新增外部反馈](../validation/FEEDBACK-0.3.3-BUILD.md)称 Creo10/0.3.3 官方构建成功（BUILD_RC=0），build.log 尾部有大量 warning/note 模板上下文。报告摘录只有note，没有原始 C4273 警告行；成功原始日志与失败路径的有界错误摘要是两种产物，不能据此认定 diagnose_build_failure 误收 warning，亦不能确认警告编号或根因。

原 DEV-028 失败摘要实现与验收保持已完成。成功/失败结果标记、成功日志分级/精简、原始 warning 消除属于后续需求，先由 DEV-030 核对完整日志、退出码与实际命令输出后定范围；不提前承诺过滤日志或改编译行为。需要保留原始诊断及详情入口，不能以裁剪note掩盖错误证据。本次仅文档补录，无新编译/单元测试或根因复验。
