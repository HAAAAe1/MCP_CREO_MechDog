
本机 0.3.4 尚未复现。报告对 `revolve(mode="cut")` 的相同判断来自源码分析，没有对应实测作业；只列为排查分支。不能把 Toolkit 返回 0 等同于切除了材料，也不能把所有合法无变化请求直接判作建模失败。

## 范围与待核实事项

先在当前源码复现 disjoint extrude cut，并核对操作前后材料、原生特征、保存和 revision。选定失败、结构化 no-op 或显式允许无变化的兼容契约，结果必须能区分实际切除与无材料变化；材料测量不可取得时明确未知，不伪填 0。`revolve` 须另取得正反例，再决定是否纳入同批实现。

本项不重开已验收的孔类守卫，不替代 BUG-016 的 side/引用核对。若采取失败或拒绝语义，须明确已创建草图/构造特征的回滚边界；若允许保留无变化特征，须明确警告、参数和 revision 契约，不继续静默当作已去料。
