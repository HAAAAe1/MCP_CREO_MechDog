外部 Creo 10.0.0.0 / MCP 0.3.3：60×40×10 板已建立 Ø8 通孔，revision=2、体积 `23497.344705562704 mm³`。追加板外圆形草图并切除：

```json
[
  {"op":"sketch","label":"sk_out","plane":"XY","entities":[{"type":"circle","name":"c1","center":[100,100],"radius":5}]},
  {"op":"extrude","label":"cut_out","sketch":"sk_out","depth":10,"mode":"cut","direction":"positive"}
]
```

报告 job_id=`de3fb70eb65d4b6cb92ae523304347e5`、model_id=`cc531259b9e8423ea6921b0a850bff5d`：终态 succeeded / success=true / Toolkit=0，体积不变，无零去料提示，保存为 `.prt.4`，revision 从 2 变 3。上述 ID 是历史证据，后续复现应新建隔离模型。

本机 0.3.4 尚未复现。报告对 `revolve(mode="cut")` 的相同判断来自源码分析，没有对应实测作业；只列为排查分支。不能把 Toolkit 返回 0 等同于切除了材料，也不能把所有合法无变化请求直接判作建模失败。

## 范围与待核实事项

先在当前源码复现 disjoint extrude cut，并核对操作前后材料、原生特征、保存和 revision。选定失败、结构化 no-op 或显式允许无变化的兼容契约，结果必须能区分实际切除与无材料变化；材料测量不可取得时明确未知，不伪填 0。`revolve` 须另取得正反例，再决定是否纳入同批实现。

本项不重开已验收的孔类守卫，不替代 BUG-016 的 side/引用核对。若采取失败或拒绝语义，须明确已创建草图/构造特征的回滚边界；若允许保留无变化特征，须明确警告、参数和 revision 契约，不继续静默当作已去料。
