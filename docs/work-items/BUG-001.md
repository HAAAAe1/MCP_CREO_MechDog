# BUG-001：未知作业的证据核对与受控模型恢复

日期：2026-10-16 补全。类型：缺陷。优先级：P0（新严重来源待现版本核实）。状态：待核实。目标版本：未排期。

来源：原台账异常任务恢复项；新增[履带反馈](../validation/TRACK-FEEDBACK-2026-10-16.md)第十七、十八节。报告环境 Creo 10.0.0.0 / MCP 0.3.2，本机尚未复现。关联已关闭的 [BUG-008](BUG-008.md)、BUG-012、[FEAT-018](FEAT-018.md)、FEAT-021。

## 现象与待验证解释

报告作业 `cf66aea4af4f46bea6aaf1549457da7b` 在约 601 s 后变成 unknown_outcome；model `c437cace0625425496fec62d8c14743a` 的 pending_job 保留，后续同模型操作被拒，磁盘仍为 rev 11。报告又称人工改状态后，后续写操作因会话几何与保存基线不一致持续失败，最终人工重启后续建成功。

这是未知结果保护与恢复能力的线索，不能把 pending_job 保留本身判成错误。报告未附完整 job/model 文件、worker 身份与原生日志；“几何已全部完成”“唯一恢复方法”“mutated 门禁是根因”等尚未核实。现有 BUG-008 关闭范围继续有效，新报告不自动将其重开。

## 范围与实施顺序

1. 在当前 main / 0.3.3 的隔离测试目录记录服务、源码/worker 指纹及正常保存基线；先确认故障前真实连接成功。
2. 对照正常长任务、保存前超时、保存已完成但重载/交付未完成、执行器退出、旧进程仍活动，以及同名会话模型偏离基线。内部故障注入只在开发者隔离件执行。
3. 核对 worker、通道所有者、作业终态、模型 revision、原生检查点、保存文件及会话状态，区分可证明失败、已保存但未完成交付、结果未知。文件存在或锁已释放均不等于作业成功。
4. 将可恢复分支交给 FEAT-018 定义的受控协调流程；无法证明安全时保留保护并返回具体原因、可取得证据及下一步。原任务不得自动重交。

不直接清 pending_job，不擅自接受 live 几何、不自动擦除用户模型、不结束 Creo，不把移除 mutated 判断或强制重载作为预定实现。诊断读取分为已持久化证据和需占 Toolkit 通道的实时查询；后者繁忙时仍按现有单通道契约拒绝，不开放并行访问。

## 验收标准

环境：Windows x64 / 本机 Creo 12.4 / 匹配 SDK 与许可；无需 Creo 10 独立复测。

| 场景 | 可判断的预期结果 |
| --- | --- |
| 正常长任务 | 预算内成功，保存重载与交付 true，revision 仅推进一次；不能因日志短暂无增量误判挂死 |
| 保存前超时 | 准确报告未知或可证明终态、最后已确认阶段；保护原基线，不能伪报回滚成功或几何未修改 |
| 保存后交付中断 | 标明保存、重载验证、终态登记各自证据；不能仅按最新 prt 后缀接受成果或更新 revision |
| 会话/磁盘不一致 | 后续写入前准确拒绝并指出不一致；受控恢复后与已确认检查点的特征、尺寸、参数、几何及文件身份一致 |
| 活动 worker / 缺失或被改检查点 | 拒绝恢复或标无法确认，不清保护、不覆盖文件；其他模型和进程不受影响 |
| 恢复后的继续编辑 | 原作业有可追溯处置记录，重复协调幂等或明确拒绝；合法后续编辑成功且保存重载，revision 不重复提交 |

开发者执行 `tools/dev_check.py --work-item BUG-001`、匹配 SDK 构建及选型后新增的隔离恢复回归；新入口在实现前不能记为已执行。WorkBuddy 只验证正式工具可观察的状态、拒绝、授权恢复及后续建模，不执行杀进程、编辑状态文件或源码探针。
