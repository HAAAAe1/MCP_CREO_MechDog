# BUG-033：原生代码硬引用 Creo 10 新增 Toolkit 常量，旧版 SDK 编译失败

日期：2026-10-15；更新：2026-10-16。类型：缺陷。优先级：P1。状态：已完成。目标版本：未排期。统一批次：[DEV-028](DEV-028.md)。

来源：[第三方用户 0.3.0 Creo 9 SDK 编译失败反馈](../validation/2026-10-15_CREO_0.3.0_旧版ToolkitSDK原生编译失败.md)。反馈环境：Windows 10 x64 19045 / Python 3.13.14 / MSVC 19.44.35229（VS2022 BuildTools 17.14）/ Windows SDK 10.0.26100 / Creo Parametric 9.0.0.0 Pro/TOOLKIT，setup.ps1 全部 9 项前置检查通过。

## 现象与根因

- 已证实现象：`setup.ps1` 前 6 阶段全部通过，最后一步原生编译失败（`INSTALL_INCOMPLETE: failed at SDK constants and native worker`）。`build/build.log` 真实错误（其余为无害 C4819）：
  - `native/geometry.cpp(104): error C2065: "PRO_E_HLE_ADD_PARAMETERS": 未声明的标识符`
  - `native/geometry.cpp(104): error C2065: "PRO_HOLE_NO_PARAMETERS_FLAG": 未声明的标识符`
  - `native/generic.cpp(179)` 同一对常量同样报错。
- 已确认根因：两常量位于 `ProHole.h`（孔特征元素树节点），为 Creo 10 引入，Creo 9 头文件不存在。两处调用模式相同：`integer(com, PRO_E_HLE_ADD_PARAMETERS, PRO_HOLE_NO_PARAMETERS_FLAG);`（创建孔特征时声明"不附加孔参数"）。除这一对常量外其余源码与 Creo 9 SDK 兼容良好（`tools/generate_constants.py` 在 Creo 9 SDK 上解析出 6109 个常量并正常生成 `native/constants.inc`）。
- 本仓库已复核（2026-10-15，main）：两处调用点仍存在，`tools/generate_constants.py` 尚无任何版本探测机制，缺陷对 0.3.0/0.3.1 均适用。

## 修复方案（已定：编译期探测宏）

1. `tools/generate_constants.py` 增加 PROBES 白名单（首批：`PRO_E_HLE_ADD_PARAMETERS`、`PRO_HOLE_NO_PARAMETERS_FLAG`），解析本机 SDK 后对实际存在的常量在 `native/constants.inc` 中输出 `#define MECHDOG_HAS_<常量名> 1`；
2. 两处调用点改为 `#ifdef MECHDOG_HAS_PRO_E_HLE_ADD_PARAMETERS` 条件编译，宏缺失时跳过该元素；与反馈方本地补丁一致（该补丁已在其环境验证：编译成功产出 `creo_worker.exe`/`creo_blend_sync.dll`，MCP 冒烟 82 工具注册、`creo_check_environment` 全部通过）；
3. 明确不采用运行时 `constant_opt` 回退，可作为长期统一机制的演进方向（暂不另开条目）。

> 2026-10-16 决定更新：本卡原写"不修改 README/COMPATIBILITY.md 支持矩阵、暂不声明支持 Creo 9"。按用户要求，Creo 9 与匹配 Toolkit 9 已在 [README](../../README.md)、[兼容矩阵](../COMPATIBILITY.md)、[安装说明](../INSTALL.md) 纳入支持/要求范围，文档同步见 [DEV-026](DEV-026.md)。DEV-026 时探测修复尚未实现；本轮 DEV-028 已落实编译保护。本机无 Creo 9 SDK，其实机编译与建模运行时均未验收。

语义影响评估（反馈方结论，合入后仍需本机回归确认）：Creo 9 下仅跳过"不附加孔参数"元数据标志，孔的几何与定位元素不受影响；Creo 10/12 上宏必然生成，行为与当前代码完全一致（constants.inc 每次构建按本机 SDK 重新生成，源码指纹机制会正确触发重编译）。

## 实现与证据

2026-10-16 复现：含两个常量的伪 SDK 经旧生成器生成后，无任何 MECHDOG_HAS 宏。实现：`tools/generate_constants.py` 增加可注入 inc_dir、固定探针集合、排序输出和 UTF-8/LF 字节比较；默认仍从本机 config.json 读取 SDK。两处孔调用同时要求两个探针存在，任一缺失即省略该元数据节点，PRO_E_HLE_ADD_NOTE 不变。

常量表原在 generic.cpp 中、位于 geometry.cpp 的底板孔定义之后；本轮前移到 geometry.cpp 的头文件区，避免仅加条件编译导致新版 SDK 下底板孔也跳过该节点。源码身份清单同时覆盖本次包内构建模块、geometry 和生成器。没有复制其他 SDK 的 constants.inc。
