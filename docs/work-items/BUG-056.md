# BUG-056：Toolkit 通道验证通过后约 40 秒静默失效

日期：2026-10-17。类型：缺陷。优先级：P1。状态：待核实。目标版本：未排期。

来源：[BUG-055 WorkBuddy 验收](../validation/BUG-055-WorkBuddy-acceptance-2026-10-17.md)中的环境干扰。用户确认掉线期间无手动操作、无 Creo 侧弹窗。与 BUG-001（已按用户决定关闭）区分：本项无卡死，通道可重连且重连后验证通过，Creo 进程存活；不据此重开 BUG-001。

## 报告现象与待核实根因

2026-10-17 WorkBuddy 黑盒会话（Creo 由用户关闭后经 `creo_startup_status(retry=true)` 重启，launch_attempt=8，Creo 12.4/release 44）期间，Toolkit 通道三次"验证通过→静默失效"（11:30:04、11:41 前后、11:43:00），每次间隔约 37～41 秒：

- 失效时 `build/toolkit_health.json`：`connected=false`、`connection_state=not_found_or_unreadable`、`toolkit_code=-4`、`worker_exit_code=20`。
- 代码映射：`not_found_or_unreadable` 对应 native 连接探测 `ProEngineerConnect` 返回 `PRO_TK_E_NOT_FOUND`（异步通信找不到会话）；exit 20 为探测失败分支的固定退出码（`native/worker.cpp` `return result ? 20 : 0`），非独立错误。
- Creo 进程全程存活（parametric PID 18720、xtop 24056）；重连协商可再次验证通过，随后再度失效。期间无建模作业占用通道（第一次掉线前），第二次掉线打断 M2 恢复作业的 native 执行（`connect_creo` -4 → unknown_outcome）。

固定 37～41 秒节奏、Creo 存活、管道"找不到或不可读"指向 Creo 侧异步通信端点的周期性消失或权限/缓存问题（许可证刷新、xtop 子进程关系、会话消息文件被清理等均为待查假设），尚无任何一项被证实。服务侧仅能观察退出码与连接码，根因需 Creo 侧证据（日志/进程关系/复现窗口）。

## 范围与核实顺序

1. 先低风险复现：重启协商后做间隔探测（如每 10 秒 `creo_session_status` 连续 3～5 分钟），确认失效节奏是否可稳定复现，记录 verified_at 与失效时刻差、是否有建模活动相关性。
2. 复现窗口内收集 Creo 侧可观察证据：`parametric`/`xtop` 进程树与启动参数、Creo 启动日志、异步通信相关目录状态（只读取证，不修改、不结束进程）。
3. 对照假设逐一排除：许可证事件、多协调器/多客户端竞争（含 `MCP_CREO_MechDog_dev` 以外的注册残留）、Creo 空闲/超时行为、本机与外部环境差异。开发者侧核对 `creo_startup` 协调器与连接探测代码路径中是否存在会主动失效健康记录的逻辑混淆（区分"探测失败"与"通道真失效"）。
4. 定位后按最小影响修复或给出操作规避；不在未定位前加重试循环或自动重连。

本项不改变 busy/串行策略、不自动结束或重启 Creo、不清 unknown 保护；涉及实机调查按 [本机联调约束](../../AGENTS.md#本机开发联调补充2026-10-17用户要求) 执行。
