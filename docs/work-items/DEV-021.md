# DEV-021：显式 MSVC 编译环境

日期：2026-10-16。类型：工程整理。优先级：P2。状态：已完成。目标版本：未排期。

来源：[Creo 9 安装反馈](../validation/2026-10-15_CREO_0.3.0_旧版ToolkitSDK原生编译失败.md)，统一批次 [DEV-028](DEV-028.md)。

## 目标与范围

支持 `config.json` 的 `vcvars64_env`（完整 INCLUDE/LIB/PATH）以及 `setup.ps1 -VcVars64Env` 参数；显式配置优先于 vcvars64.bat，环境检查不要求该文件存在，构建保留 compiler_preflight 前置自检。拒绝非法结构、缺失或空值、引号/百分号/换行等非法字符；安装保留已有额外配置。缺省 null 沿用原路径。不自动探测或写入全局环境，不生成受限环境包装脚本。

## 验收标准

夹具验证配置校验、环境检查、build.cmd 两分支及实际 cmd 赋值、安装参数优先级/回写/属性保留；缺编译器与 SDK 的显式环境仍由自检拒绝。统一开发检查与本机 Creo 12.4 回归通过，受限环境实机安装不外推。

## 实现与证据

2026-10-16 实现：包内 build_support 校验恰好三个大写键与非空字符串，拒绝 NUL/换行/引号/百分号；bridge.py 的 config、环境报告和 build.cmd 均支持该分支，使用带引号的 set 和 DisableDelayedExpansion，保留 compiler_preflight。setup.ps1 增加 -VcVars64Env、相同校验、选项优先级及持久化，保留未知配置属性；显式 -VcVars64 切回原路径，未传两参数时沿用配置。

配置负例、无 vcvars 文件且环境完整、缺 SDK 仍拒绝、默认 null/缺省兼容、构建脚本及真实 cmd 特殊字符赋值、PowerShell -CheckOnly/参数回写/属性保留/参数优先级夹具均通过。临时安装夹具在写配置后受控停止，不修改项目 .venv 或 config.json。

受测提交基点 `b6c7daff61bc9f2ef288b5984f823a9945ab8710`，dirty=true，版本 0.3.1；Windows x64 / Python 3.12.14 / Windows PowerShell。源码指纹及统一结果见 [DEV-028 验证](../validation/DEV-028.md) 及其 JSON。全新受限机器安装、注册表策略受限场景未实机复现；本机 Creo 12.4 原生构建使用原有经审核的编译器包装入口，与显式环境夹具分开记录。

## 2026-10-16：0.3.3 受限环境外部正例与额外键请求

[外部报告](../validation/FEEDBACK-0.3.3-BUILD.md)提供 Windows10/Creo10/Python3.13、工程根含空格、reg.exe受限的正例：完整环境转储因额外SDK变量被校验拒绝，裁剪为 INCLUDE/LIB/PATH 并并入实际SDK路径后，官方 bridge.py build 成功，三截面自动匹配体积约22160mm³、保存重载true；没有原始job/model和完整安装记录，本机未重新执行该环境。该正例不替换前述本机/夹具身份，也不等于受限机器完整安装已验收。

原实现状态保持已完成；后续请求由DEV-030先核对再登记实现范围。本次不改环境键校验、子进程环境、安装回写、config.json或系统策略，不将额外键透传写成已支持。
