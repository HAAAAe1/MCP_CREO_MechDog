# FEAT-037：参数作用域、同名消歧与拼写提示

日期：2026-10-17。类型：功能。优先级：P3。状态：待规划。目标版本：未排期。

来源：[0.3.3 反馈补录](../validation/FEEDBACK-0.3.3-2026-10-17.md)报告 B 第 11 节；关联 FEAT-004/006/008。

## 目标与范围

报告提出模型级/特征级参数易重名、拼错无候选提示，未提供失败输入、对象身份或实际误写证据，先作为易用性建议，不认定已发生参数串写。

先取得同名模型/特征参数的最小场景，核对现有 scope、特征引用、查询、设置和关系引用规则。评估显式作用域/限定名称、歧义拒绝、原样返回解析对象及有界拼写候选；不默认改名或新造一套参数存储，不自动把相似名称当目标。保留既有无歧义请求兼容，关系控制和只读限制继续有效。

## 验收标准

| 环境 / 用例 | 可判断的预期结果 |
| --- | --- |
| Windows / 解析与回归 | 同名/不同名、缺 scope、非法或过期特征引用、拼错参数均有确定结果；候选有界，未确认不写入；统一开发检查通过 |
| 本机 Creo 12.4 / 匹配 SDK | 同名模型参数与两个特征参数可分别查询/修改，回读对象与原生值准确；关系引用无串写，revision 和保存重载正确 |
| 拒绝与 WorkBuddy | 歧义、关系控制或拼写错误不改变模型；WorkBuddy 仅 MCP 记录目标作用域、前后值、错误及持久化结果 |

## 实现与证据

本次仅登记待澄清建议，未实现命名空间或提示机制。当前 0.3.4 无本机复现记录，不因来源报告措辞直接升级为缺陷。
