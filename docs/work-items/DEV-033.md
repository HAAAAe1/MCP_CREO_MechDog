## 最小验收矩阵

测试模型应逐场景隔离。建议基准为 XY 平面 60×40、厚 10 的板，范围 x=−30..30、y=−20..20、z=0..10，先在 (−10,0) 建 Ø8 通孔。确认实际建面/方向后，基准解析体积 `24000−160π mm³`。外部报告的历史模型 ID 不直接复用。

| 场景 | 操作与可判断的预期结果 |
| --- | --- |
| T01 有效切除 | (15,0) 的 Ø4 圆拉伸切透，明确方向和实际深度 10；应去料 `40π mm³`，最终体积 `24000−200π mm³`。原生特征和轴向正确，保存重载 true，revision 按契约推进一次 |
| T02 板外切除 | 圆心 (100,100)、R5、深 10；材料不变时返回 G2 选定的可识别失败/no-op，不能仅普通 succeeded 且无说明。若失败，模型/特征/别名、检查点和 revision 恢复到本作业前状态 |
| T03 重复切除 | 在已去除的完整区域重复切除，核对实际零变化与 T02 的同一结果契约；不通过创建无效特征掩盖结果 |
| T04 边界与小量有效去料 | 分别构造相切、共面、局部交集和小量有效去料；独立计算预期材料差量，记录模型精度与容差，不能凭 bbox 相交或粗阈值把有效小切除拒绝 |
| T05 多操作计划 | 已有保存基线后提交“草图→切除→后续操作”；失败时检查整份计划的回滚范围和别名/revision，不能只删除最后一个特征留下半成品；随后有效编辑仍可成功并重载 |
| T06 未知与拒绝边界 | 离线夹具覆盖材料测量不可取得、原生失败、过期 revision、已有未知保护和收尾错误；状态准确，不伪造去料/回滚成功，不清保护或自动重提 |
| T07 旧行为回归 | 有效孔、板外孔、普通 add 及 surface 分别验证适用范围；保留 BUG-022 的材料守卫与原公开兼容。未受本次修改影响的分支不扩大宣称已验收 |
| T08 revolve 对照 | 仅在满足纳入条件后，使用显式轴建立可独立计算体积的有效切除及无交集对照，核对材料、结果契约、回滚和重载；未做则明确未验证 |

## 实现落点与验证分层
