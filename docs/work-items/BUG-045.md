# BUG-045：装配欧拉角与查询矩阵的方向契约不清

日期：2026-10-16。类型：缺陷。优先级：P2。状态：待核实。目标版本：未排期。

来源：[0.3.1 实体配电箱报告](../validation/feedback-2026-10-16/2026-10-16_CREO_0.3.1_多区域截面拉伸与共面合并等10项缺陷.md) P5，钣金报告第七节；[补录](../validation/FEEDBACK-2026-10-16.md)。关联 FEAT-008、BUG-036。

报告称 rotation=[0,90,0] 得矩阵 [[0,0,-1],[0,1,0],[1,0,0]]，改 [0,-90,0] 得反向矩阵并满足 local +X→global -Z、+Z→+X。jobs `1f7ae831ff994ff191228a63089c5c2b` / `95fad65c9e2a407c8c1ff6e44ebb2182`。矩阵如何作用于行/列向量、局部/全局变换方向尚未确认，不能直接断言符号实现错误。

范围与验收：明确右/左手、主动/被动、欧拉施加顺序、矩阵存储与单位，并对 assemble_component/update placement/list_components 保持一致。X/Y/Z 单轴 ±90° 及组合旋转用三个基向量和已知点验证，平移与坐标映射可复算，保存重载后不变。若仅文档有歧义，保留既有输入兼容；若需改语义，先制定兼容与迁移规则，不直接翻转所有角度。

后续在 Windows x64 / 本机 Creo 12.4 / 匹配 SDK 做适用检查、矩阵映射与装配实机回归。报告具体 Creo/OS/构建无法确认，本次仅登记。
