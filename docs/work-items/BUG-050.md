## 现象与假设

外部 Creo 10 / 0.3.2：相切直线+圆弧水密闭环在 coordinates 模式求解/再生返回成功，回读几何最大偏差 0.487310 mm，超过报告所述 1e-5 mm 自检而失败；分离圆弧和纯直线闭环对照成功，人为断开端点后草图可建但扫描不闭合。报告同时写“5 线+5 弧”和“10 线+5 弧”，实际完整输入未提供，须先核对。

“合并顶点后仍逐端点发尺寸导致过约束”、自由度数量及 1e-9 顶点合并阈值是待验证解释，不直接作为 SDK 契约。不能仅放宽回读容差或人为开缝绕过闭合要求。

## 范围与验收

1. 固定高精度端点、圆心/半径、圆弧方向与实体顺序，分别测试单段、两段相切、闭合线弧链、纯线及非连接弧；区分源坐标舍入误差和约束/尺寸化引入的偏移。
2. 核对端点共享、约束及驱动尺寸引用，选择不重复约束且保留输入几何的最小改动。必要的归并规则要有可验证容差和回显，不能自动扭曲输入。
3. 在独立草图和实际闭合扫描中验证，保留原生可编辑尺寸与下游引用。

| 用例 | 可判断的预期结果 |
| --- | --- |
| 精确共享端点的相切闭链 | 端点、半径、角向及闭合性在冻结容差内与输入一致，不静默移位；原生尺寸可查询、编辑和重载 |
| 纯线 / 分离弧对照 | 既有成功能力不退化，两个草图入口的同模式行为一致 |
| 舍入/近闭合/非法约束 | 准确指出偏差、实体与阶段；未经明确契约不吸附、不放松自检、不改输入补缝 |
| 下游扫描与失败恢复 | 合法闭环扫描正确、保存重载 true；失败时检查点/revision 保持，后续合法输入可用 |

Windows x64 / 本机 Creo 12.4 / 匹配 SDK：开发统一检查、尺寸/引用回归、受影响构建与原生线弧套件；WorkBuddy 只验证公开 MCP 草图/扫描及回读。源 Creo 10 不设置独立复测门槛。
