# BUG-061：草图字典平面的非零 offset 被拒

日期：2026-10-18。类型：缺陷。优先级：P2。状态：待核实。目标版本：未排期。

来源：外部 0.3.5 钣金第四轮回归反馈的 P3（本轮未复测，沿用 0.3.3 实测），见[原件](../validation/FEEDBACK-0.3.5-SHEETMETAL-2026-10-18.md)。关联 [BUG-031](BUG-031.md)（mirror 基准面 offset 的同类语义问题）、[FEAT-008](FEAT-008.md)（字典平面是引用已有面还是新建偏移面）。

## 报告现象（0.3.3 实测，0.3.5 未复测）

草图 `plane` 传字典形式（如 `{reference:…, offset:非零}`）时被拒；0.3.5 轮未复测。使用者目前只能先 `creo_datum_plane` 建面再按 label 引用。

## 待核对

- 字典平面 + offset 的预期语义：是引用已有面，还是隐式新建偏移面（FEAT-008 要求说清的问题）；
- 拒绝时的报错是否提示替代路径（先建 datum_plane 再引用）；
- 与 BUG-031（mirror offset）是否同一解析路径，修复时一并核对，不各自放宽。

## 范围

仅草图 plane 字典输入的 offset 分支与报错；不改变 XY/XZ/YZ 简写与显式 datum_plane 引用的现有行为。

## 验收标准

| 环境 / 用例 | 命令或操作 | 可判断的预期结果 |
| --- | --- | --- |
| Windows / Python | schema 与离线校验核对 | offset 行为有明确契约：生效（含新建面）或准确拒绝并提示替代路径 |
| 实机（待复测） | 字典平面 offset 草图对照 | 生效时几何/方向正确且可重载；拒绝时模型与 revision 不变 |
