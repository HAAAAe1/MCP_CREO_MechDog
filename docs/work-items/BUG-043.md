# BUG-043：增料与父体共面接触时合并失败

日期：2026-10-16。类型：缺陷。优先级：P1。状态：已完成。目标版本：未排期。

**2026-10-16 结论**：[0.3.2 报告 A](../validation/FEEDBACK-0.3.2.md) P2 在 v0.3.2 上以 10×10×10 草图置于底块顶面（Z=10）、`add(depth=10)` 成功并入同一实体（`bodies:1`、体积 +1 000，job `194f59d6ff9e40559d1aa9d1f82313e9`）。按用户 2026-10-16 决定采信该外部结论转已完成并移入[归档](../BACKLOG_COMPLETED.md)：本仓库无对应修复提交可核实，未在本机复验共面合并；本机复现失败须重开本 ID。下方原来源、范围与未测边界保留。

来源：[0.3.1 实体配电箱报告](../validation/feedback-2026-10-16/2026-10-16_CREO_0.3.1_多区域截面拉伸与共面合并等10项缺陷.md) P2；[补录](../validation/FEEDBACK-2026-10-16.md)。关联 BUG-042、BUG-044、FEAT-006。

共面 add/new_body=false 报 -1（job `821e2459c33943d99da2f81876037732`）；同几何 new_body=true 成功为两体（`be5b4b1caf9044b992951d847e457a06`），隐藏 1 mm 重叠后可合并。竖直咬合舌失败（`8f3d466d6d9547caaef7b8b5d21ecc56`）、斜舌成功，报告推测 cusp/反向切线。

范围与验收：单区域合法截面，有限面积面接触、正体积重叠、间隙、仅边/点接触及退化截面分别对照；补完整模型、公差、方向与表面/边拓扑。能创建独立 body 不代表与父体 union 一定合法，不能用报告直接确认合并算法根因。

支持的面接触增料应为预期单体、材料体积/外形与解析值一致，原生特征健康、保存重载 true、revision 正确。非流形/间隙/退化或明确不支持组合应准确区分并恢复检查点，未知原因保留原始诊断；不为通过而默认暗加重叠材料。截面预检与错误上下文衔接 FEAT-006。

报告未给具体 Creo/OS/源码身份；后续在 Windows x64 / 本机 Creo 12.4 / 匹配 SDK 执行适用检查、接触/合并原生回归。本次仅登记。
