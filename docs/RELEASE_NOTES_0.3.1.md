# MCP_CREO_MechDog 0.3.1：建模稳定性与查询结果修复

日期：2026-10-15。主干服务/源码版本同步；保留原提交历史。补丁位0.3.0→0.3.1由用户明确确认，包含下述默认查询响应调整，调用方需适配。GitHub Release和附件发布独立记录。

## 改动

- BUG-007：放样回调预先初始化，避免建模时等待DLL确认；未就绪明确失败并给出初始化指引。标签引用两/三截面straight/smooth、已有底座追加和失败后通道通过本环境WorkBuddy验收。
- BUG-028：loft.sections兼容整数、纯数字字符串与标签，归一化后检查重复；独立工具和计划使用相同规则，不做全局字符串转换。
- BUG-021：改进关系控制尺寸的拒绝提示和首个失败调用定位，验证简单件/含放样件自由尺寸、关系驱动、参数传播及恢复后继续修改。
- BUG-022：显式选择点稳定实体边参考孔定位；补直边、共面和独立性校验；无去料明确失败并回滚。成功操作详情返回原生孔轴和material_removed_mm3。用户确认本环境WorkBuddy最终四场景全部通过。
- BUG-017：修正原生筋材料侧设置顺序，验证开放相交剖面、flip和厚度侧，拒绝闭合及不相交剖面。
- BUG-014：区分真实零值和未知/null；失败中间状态与恢复后inspection分开；空件体数量不等于存在实体，plate仅返回实际可核实计数。
- BUG-013：模型列表和检查默认摘要，完整详情按section/游标分页；游标绑定快照，模型变化后重新查询。查询内容预算32KiB，详情默认50条、最多200条。

## 调用迁移

`creo_list_models`、`creo_inspect_model`默认`detail="compact"`。依赖完整inspection的客户端需传`detail="full"`，有`next_cursor`时沿原查询继续读取，直至`complete=true`；按需使用section筛选。模型变更使旧游标失效，应从无游标查询重新开始。不能把第一页当完整模型快照；仓库内相关示例及测试已迁移页收集逻辑。

`creo_get_job`保留既有detail默认值。缺失计数使用null；调用方应分别处理未知值与0。孔完全重合、板外或切削反向且无实际去料时，现在返回失败并回滚，不能只以原生特征创建成功判断几何有效。
