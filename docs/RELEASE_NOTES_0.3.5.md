## 本版行为

- **BUG-054 / DEV-033：** 拉伸、旋转的实体 cut 在创建/再生前后核对材料体积。实际零去料时返回可识别错误并回滚本作业，revision 和保存基线保持；有效切除返回 `material_removed_mm3`，compact 结果保留该值。add/surface 原行为保持。实体有效/板外/重复/边界切除、整计划回滚与后续编辑已有本机 Creo 12.4 实机及 WorkBuddy 验收。
- **BUG-055 / DEV-034：** 恢复 `expected_pending_job_id` 接受 JSON null 或省略；非空必须是有效 job ID，空串/空白/畸形值准确拒绝并回显实际收到值。revision 与 pending 的真实 stale 分别报告实际/期望值，令牌、所有者、幂等和 busy 保护保持。WorkBuddy 客户端把显式 null 转为空串的限制已观察到，省略字段路径完成恢复闭环；直接 Python 调用不代替 MCP 验收。
- 原始 0.3.3/0.3.4 外部反馈、任务卡、验收、BUG-056 新线索和 DEV-026 历史计划一并提交；重复主题沿用既有 ID，历史原件及失败记录保留。

## 升级

安装新源码后同步 editable 包，按正式安装/构建步骤重建本机执行器，并重新连接 MCP 使新定义与启动指纹生效。恢复输入用 inspect 返回的 revision、pending、token 和明确选定动作；无 pending 时发送 JSON null，客户端无法保真时省略该字段，不能填空串。已有未知作业不得自动重放或人工清除保护，详见[恢复说明](MODEL_RECOVERY.md)。

新增切除守卫会拒绝过去可能静默成功的无交集切除，应核对实际方向、深度、引用及已去除区域；合法大弧、solidify、thin/装配/钣金 cut 不因本次实体切除验收自动扩大支持。
