# MCP_CREO_MechDog 0.3.2：通道恢复与任务收尾

日期：2026-10-16。补丁版本，发布为 Pre-release。累计包含公开 0.3.0 之后的 0.3.1 建模与查询修复；0.3.1 当时只完成主干集成，本次不补造历史 Release。

## 改动

- BUG-008：结果先写检查点再断开，断开等待有界；未知结果继续保护原任务与模型。实时探针超时返回结构化诊断，旧 ready 标明陈旧。系统重启前损坏的共享启动历史，在开机时间可核实、无现存或不确定 Creo 会话等安全条件成立时，先原字节备份再重建并协调单次自动启动。同次开机损坏、证据不足或备份失败仍安全停止并说明人工处理办法。
- BUG-009：在模型锁内完成登记收尾，释放后发布终态，避免立即续编误报 busy；占用时保留协议错误并给出诊断。
- DEV-002 第二批：校验、翼型、轮廓辅助实现迁入 `creo_mechdog` 包，兼容入口继续可用；源码安装和分发按 editable 方式核对，运行数据位置不变。整体迁移继续分批推进。
- 同步 WorkBuddy/用户反馈原件、已完成验收范围和唯一台账，以及合入 main 同流程发布规则。未实现的缺陷和能力建议仍为待办。

0.3.1 中的放样初始化/引用、孔/筋、尺寸关系诊断及查询分页变化，详见 [0.3.1 说明](RELEASE_NOTES_0.3.1.md)。`creo_list_models`、`creo_inspect_model` 默认摘要；需要全量时传 `detail="full"` 并收集全部分页。

## 验证与边界

本次发布检查、受测源码身份、实际命令及结果见 [0.3.2 发布记录](validation/RELEASE-0.3.2.md)。当前原生验收环境为 Windows x64 / Creo 12.4.0.0 / 匹配 SDK。历史开发者真实冷启动与 WorkBuddy 正例分别引用 [BUG-008 关闭记录](validation/BUG-008-closure-2026-10-16.md)，不改标成本版新 WorkBuddy 结果。

历史完整 transform→保存未交付→-38 链未复现；本版不保证任何受损会话都能自动恢复。BUG-001 未知任务对账、BUG-005 宿主连接差异、BUG-011 更广状态诊断继续跟踪。未重新执行所有建模模块及所有参数分支；没有本次 Creo 10 或其他维护版本实机证据，不跨环境外推。

## 升级

等待现有任务终态，保留配置、models/jobs 和未知任务记录，更新完整源码及配套 seed_library。使用 Python 3.12+ 安装锁定依赖并以匹配 SDK 重新构建，重启 MCP 连接器后核对公开接口版本 0.3.2。已有 Creo 会话可复用；放样仍须在该会话初始化配套常驻回调。

九个种子 PRT 的 SHA256 保持不变，两份清单及独立 ZIP 摘要同步到 0.3.2。附件为源码 ZIP、种子 ZIP 及各自 SHA256；源码包不携带本机配置、二进制执行器、PTC SDK、许可或运行模型。最终标签、主干提交和远端附件下载校验结果在合并 PR 回填。
