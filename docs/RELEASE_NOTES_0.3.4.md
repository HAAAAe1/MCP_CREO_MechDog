# 0.3.4：受控模型恢复与回调生命周期集成

日期：2026-10-17。类型：源码Pre-release。用户明确指定0.3.4，作为本版新增公开工具仍递增PATCH的版本规则例外。

## 本版内容

- 新增 `creo_reconcile_model`：持久化诊断、实时预检，以及显式恢复基线、接纳保存候选、接纳会话模型、放弃无基线新件四种处置。令牌、revision、幂等和持久化登记保护原始未知结果，不自动重放原计划。
- 收紧普通写路径，拒绝会话偏离及无基线半成品的隐式采纳；保留异常证据与原作业历史。
- 集成FEAT-029的固定 `build/blend_callback_protk.dat` 注册入口、不可变引导/载荷及 `creo_callback_status`。当前注册84个MCP工具；prepared与实际ready分开，建模和查询不自动加载DLL或修改安全策略。
- 汇总DEV-030任务卡、履带/构建反馈、G0复现、E盘证据同步及卡死离线排查，保留原始报告环境和字节。

## BUG-001关闭与验收边界

BUG-001按用户本次决定关闭，不代表卡死根因已修复或完整验收通过。已有证据确认Creo12.4连接初始化通信失败（trail `-97`、客户端 `-11`）及同一进程随后无响应；底层诱因仍未确定，不能认定SDK版本选错。

FEAT-018与FEAT-029仍为验收中。本版不新增Toolkit连接、原生建模、故障注入或WorkBuddy复测；原生四动作的部分既有通过及整轮失败均保持原记录。最新集成代码的完整恢复矩阵、正常长任务、生命周期升级/回退/并存和WorkBuddy仍未完成。详见[本版验收范围](validation/RELEASE-0.3.4.md)、[恢复记录](validation/BUG-001-recovery-2026-10-17.md)及[离线卡死记录](validation/BUG-001-hang-offline-2026-10-17.md)。后续复现沿用BUG-001重开。
