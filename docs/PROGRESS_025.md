## 验收规则

建模案例检查原生特征保留、参数修改成功、保存后擦除并重载成功；适用案例额外核对实体体积、STL 截面/边界及回滚后实际模型。拒绝非法输入、超时或未知结果不计作建模成功。已完成任务 ID 写入证据，不通过重复提交替代检查。

## 范围

- 直接 Blend：受管独立 XY 草图、实际 Z 严格递增、默认实体增材，直线或平滑；不提供非平行、切除/曲面、新实体和端点相切/曲率控制。
- 坐标草图：主平面上的直线/中心线/矩形/多段线/圆/圆弧，无调用者显式尺寸/约束；样条、椭圆及任意方向面沿用 autodim。没有启用缩放或刚性求解。
- 扫掠：恒定截面，四个代表性组合；不据此宣称所有轨迹、框架和相交情形通过。
- 种子：数量和模式必须匹配。九个组合通过验收不代表接口 2～20 的每种组合均已实测。
