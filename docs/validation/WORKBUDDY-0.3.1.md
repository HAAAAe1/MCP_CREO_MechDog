## 后续验收缺口

- 直接 `creo_loft`：测试发起者按能力接口/准备文件完成常驻回调注册并确认策略后，再由 WorkBuddy 测成功路径。报告尾部请求人工操作仅作历史上下文，本次未注册 DLL 或改变 Creo 设置。
- UDF：提供可分发的最小 `.gph` / `.gph.N` 夹具，分别验收 inspect/create 成功路径；扩展名校验通过不等于 UDF 正向通过。
- 元素树：有效最小 dict、完整原生诊断及 dump/import 语义，归 FEAT-026；无效树负例与正例分开。
- 种子安装：directory/archive_file 两分支使用合法夹具，分别验证发现、校验及安装结果；本轮仅无参分支。
- 导出：本轮 STL/STEP/IGES 正向；JPEG 未测，PDF 仅验证非图纸输入拒绝，需图纸正向验收。旧版 JPEG 成功不改称本轮通过。
- 并发：补真实起止时间线、全部提交响应与 holder/retry 信息，验证终态后提交及同模型 revision 保护；不以报告中的 busy 拒绝算排队/并发通过。

本次未修复程序或改变运行支持声明；新增建议的具体实现方案须在复现、契约核对与独立验收后确定。
