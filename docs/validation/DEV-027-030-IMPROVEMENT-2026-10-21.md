## 一、DEV-027 构建指纹稳定化

实现：新增 `src/creo_mechdog/build_fingerprints.py`（CRLF→LF 归一化、规范化指纹算法 `sha256-repo-lf-v1`、旧算法三形式重算 `legacy_digest_candidates`、缓存匹配 `match_cached_fingerprint`）；`bridge.build_native` 改造为：

- worker/callback/loader 指纹对仓库原生文本依赖按归一化内容计算；SDK 头、有效配置、二进制 SHA256 与发布附件保持原始字节。
- 构建缓存增加 `algorithm` 与 `generation_key`；`blend_callback_setup.json` 的 `loader_fingerprint` 继续表示实际目录键（消费方不变）。
- 旧缓存（无 algorithm 标记）按原始/LF/CRLF 全组合重算原算法：精确命中且 DLL 或不可变镜像 SHA 正确才复用原世代与注册路径；复用出口把缓存升级为新格式。
- 无法证明等价时重编并打印原因（stderr，仅构建进程）；世代目录被历史镜像占用时派生 `<指纹>-<sha256[:12]>` 键并存，历史不可变副本不动。
- 发布顺序：先 `prepare_callback`（逐文件原子），成功后才写 DLL 缓存标记与 `source.sha256`（原子写）；中断后下次持锁构建重新验证。

### 单元测试（tests/unit/test_build_fingerprints.py，8 项）

LF/CRLF 规范指纹等价且两原始形态均入 legacy 组合；真实内容变化必然改变指纹；缓存匹配接受 algorithm 标记/legacy 等价/拒绝不匹配；`build_native` 级：0.4.x 遗留安装（原始字节缓存+世代目录）行尾翻转后复用旧世代（目录数不增、注册内容指向旧键、仅 worker 重编一次、第二次快速返回）、纯行尾翻转连 worker 都不重编、不可证明等价重编进新世代、非确定性重编回到历史指纹时派生键共存且历史副本字节不动、元数据发布中断不误报成功且下次构建收尾。全套 469 项单元 + `tools/dev_check.py` 通过（无新增诊断、无基线豁免）。

## 二、DEV-030 vcvars64_env 放宽

实现：`build_support.validate_compiler_env` 要求大写 INCLUDE/LIB/PATH 三键必须存在，其余键接受并忽略（仅键名提示一次，stderr，不回显值，不进有效配置/构建脚本/指纹）；缺键错误列出缺失项与最小配置示例；`setup.ps1` 同口径校验（大小写敏感检查三键）且回写规范化三键、保留其他配置属性。不新增 MCP 工具、不改 ABI/协议。

验证：单元测试覆盖三键/额外键/缺键/大小写/非法值、忽略项不进 build.cmd、PowerShell 缺键报错含缺失项与示例、额外键 CheckOnly 通过且回写仅三键、原三键/vcvars 路径优先级不变（tests/unit/test_install_config.py，469 项全量通过）；实机以真实 MSVC 三键+额外键完成构建（见上表）。
