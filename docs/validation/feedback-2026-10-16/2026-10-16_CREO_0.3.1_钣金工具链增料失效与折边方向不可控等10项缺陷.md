# MCP_CREO_MechDog 钣金工具链问题反馈报告

- **日期**：2026-10-16
- **MCP 名称 / 版本**：MCP_CREO_MechDog，**v0.3.1**（`creo_capabilities` 返回 `version: 0.3.1`，`tool_count: 82`；`creo_capabilities.update` 报 `current_version 0.3.1` > `latest_version 0.3.0`）
- **Creo 环境**：Creo Parametric（xtop.exe），由 MCP `auto_start` 自动拉起，`units: mm`
- **复现任务**：《配电箱_跨软件自然语言建模说明.txt》——**要求本次全程使用 MCP 的钣金工具**（`creo_new_sheetmetal` / `creo_sheetmetal_wall` / `creo_sheetmetal_flange` / `creo_sheetmetal_unbend` / `sheetmetal_bend_back`）重新近似设计配电箱（箱体 + 门板 + 打开姿态装配）
- **结果概览**：钣金箱体（38 特征 / 1 实体 / V=74 981.33 mm³）与钣金门板（19 特征 / 1 实体 / V=30 650.11 mm³）已建成，装配 2 组件、V=105 631.44 mm³（精确等于两者之和）；**展开（unbend）与折回（bend back）往返闭环成功，折回后体积精确恢复 74 981.33 mm³**。但钣金工具链存在 **3 项阻塞级缺陷**，导致"完整三段折边四壁配电箱"在当前版本下**无法只用钣金特征建成**。

## 一、阻塞级缺陷

### S1. 钣金模型上 `extrude(mode="add")` 一律失败（切除正常）——钣金件上无法做任何实体增料

- **现象**：在 `creo_new_sheetmetal` 建立的钣金零件上，任何 `extrude` 的 `mode:"add"` 都报
  `Toolkit call ProFeatureWithoptionsCreate failed with code -1 during execute_extrude`（`toolkit_code: -1`）。
- **对照实验**（同一模型 `56d4cdae6b7242929d7180949905ef1a`，钣金）：
  | 场景 | 结果 |
  |---|---|
  | ⌀10 诊断圆、`through_all` **切除** | ✅ 成功（体积 78 970.58 → 78 892.04，精确减少 π·5²·1=78.54） |
  | 10×10×5 诊断块，**增料**（与底板明显体积重叠） | ❌ 失败 |
  | 10×10×5 增料（重试） | ❌ 失败 |
  | 155×1×76.46 端壁板增料（与既有壁体积重叠） | ❌ 失败 |
- **关键排除**：失败与"共面接触 / 多区域截面 / 角部干涉 / bodies=2"均无关（最小诊断块全部排除）；失败后 `bodies: 1`，切除仍正常。
- **影响**：**钣金件上无法添加任何实体**——格栅筋条、底板冲压凸台、铰链座与销、端壁四孔所在壁、第二/三段折边框边，全部无法实现。本次只能把格栅改为 **32 个开口直接切除**（反而更贴近 TXT §6.3），其余特征被迫放弃并披露。
- **违反能力声明**：`creo_capabilities` 的 `operations` 列表包含 `extrude`，`sheetmetal` 一节只声明了 "bend relief, forms, hems and jogs are not high-level tools"，**未声明增料在钣金件上不可用**。
- **建议**：修复；或至少在文档/报错中明确"钣金模型仅支持 cut"，并返回可识别错误码（如 `SOLID_ADD_ON_SHEETMETAL_UNSUPPORTED`）而非裸 `code -1`。

### S2. `sheetmetal_flange` 弯曲方向不可控：`flip` 参数无效，第二段"向内框边"做不出来

- **现象**：`flip` 传 `false` / `true` 得到**完全相同**的几何（仅因 height 不同而体积差 232 mm³）：
  | 参数 | 实测 |
  |---|---|
  | 底板下缘（Z=0）挂接，h=80，flip=false | 壁向 **+Z**（向上）✅ |
  | 底板上缘（Z=1）挂接，h=80，flip=false | 壁向 **−Z**（向下） |
  | 底板上缘挂接，h=79，flip=**true** | 壁仍向 **−Z**（向下）❌（flip 未翻转方向） |
- **规律（实测）**：折边**始终背离该壁的驱动面**方向弯折；因此壁（内表面为驱动面）顶部再折边时，**只能向外**。
- **直接后果**：TXT 要求的"围壁顶部四条内缘向内折 20 mm 形成水平框边"，实测从壁顶边（无论挂内缘 220 还是外缘 219）得到的都是 **X=91.5 → 111.5 的外伸框边**（两种挂接方式体积完全相同 87 181.16 mm³），**向内 20 mm 无法实现**。
- **建议**：让 `flip` 真正翻转折边方向；或在返回中回显折边方向/边界盒，并在文档中写明方向判定规则。

### S3. `sheetmetal_flange` 无法建"封闭四壁盒"——第 3/4 条垂直折边必失败（无折弯释放）

- **现象**：底板第一壁建成后，在 ±X 底缘各挂一道折边（满长）成功；再在 ±Y 底缘挂折边时报
  `Regeneration produced a failed, suppressed or incomplete feature`（`toolkit_code: -1`，`failed_stage: execute_sheetmetal_flange`）。
- **已排除**：与弯径无关（**R2.54 与 R1.0 均失败**）、与 `flip` 无关。
- **根因**：±X 折边弯折后已把底板下缘四角"吃掉"（±Y 底缘边被裁到 X=±88.96），±Y 折边两端落在弯折圆柱面上；而 MCP 明确声明 *"bend relief, forms, hems and jogs are not high-level tools"* —— **没有折弯释放（bend relief）**，因此垂直折边在角部必然冲突。
- **影响**：**四壁开口箱无法只用钣金折边建成**（最多 2 面相对壁）。这与 Creo 自身 UI 能力（4 道折边自动加释放/延伸）不一致。
- **建议**：提供折弯释放参数（矩形/扯裂/圆形）或自动角部处理；至少给出可读原因而不是裸 `code -1`。

## 二、接口与文档缺陷

### S4. `sheetmetal_wall` 的 `depth` / `thickness` 语义未文档化，且与直觉相反

- **实测语义**（通过边缘坐标反推）：
  - 草图**线长** → 壁的一个面内尺寸（185）
  - `thickness` → **面内**垂直于草图线的尺寸，且**以草图线为中心**
  - `depth` → **垂直于草图平面**的方向（不是面内！）
- **复现**：目标"185×232×1 水平底板"。第一次传 `depth=232, thickness=1`，得到 **185(X) × 1(Y) × 232(Z)** 的竖直板（体积 42 920 却方向错）；第三次传 `depth=1, thickness=232`，得到 **185 × 232 × 232**（体积 9 957 440 mm³，体积错误！）。
- **最终可用路径**：草图必须画在 **YZ 平面 + offset**、线沿 Y（长度 232）、`thickness=1`、`depth=185`、`direction=negative`，才得到 X±92.5 / Y±116 / Z0~1 的正确底板（体积 42 920 ✅）。
- **建议**：在 `creo_sheetmetal_wall` 描述里写清三个方向与"thickness 以草图线为中心"；并提供"按面内矩形直接铺底板"的常用入口。

### S5. `sheetmetal_wall` 的 `depth=1` 结果异常（被 thickness 值覆盖）

- **复现**：`depth=1.0, thickness=232.0` → 实测 Z 向尺寸 = **232**（应为 1），体积 185×232×**232** = 9 957 440 mm³。
- **推断**：`depth` 存在隐式下限或被静默替换为 `thickness`；而 `depth=185 > thickness=1` 时正常。工具无任何提示。
- **影响**：**无法用 `sheetmetal_wall` 直接铺 1 mm 厚底板**，只能绕道（草图放在 YZ 平面、令 thickness=1、depth=面内长边）。
- **建议**：修复并对非法/被改写的参数返回明确告警。

### S6. `sheetmetal_unbend` 的 `fixed_surface` 不接受 datum_plane，且报错无指向

- **现象**：`fixed_surface = {kind:'datum_plane', axis:'z', offset:0}` 报
  `ProFeatureWithoptionsCreate failed with code -1 during execute_sheetmetal_unbend`；
  改传真实面 `{kind:'surface', id:103}` 后**成功**（37 特征，体积 74 981.33 → 74 848.91）。
- **附带**：`references` 省略可一次展开全部折弯 ✅；`sheetmetal_bend_back` 同法成功且**体积精确回到 74 981.332**（往返闭环 ✅，值得肯定）。
- **建议**：支持 datum_plane 作固定面；或报错时提示"请传 `{kind:'surface', id:N}`，可用 inspect_model(section=surfaces) 获取"。

## 三、会话与可观测性

### S7. Creo 会话跨日断开：建模调用不等待后台启动，立即失败

- **现象**：隔日再调用，`creo_new_sheetmetal` 立即失败
  `Toolkit call connect_creo(&process) failed with code -4 during connect`（`PHASE=connect / BUILD_FAILED=-4`）；
  同时 `creo_startup_status` 长时间停留在 `state: "checking"`、`connected: false`，**从不给 ready 信号**，而后台确实在拉起 xtop（进程可见）。
- **建议**：建模类工具在会话未就绪时应等待 `creo_startup_timeout_seconds` 或返回明确的 `NOT_READY`，而不是裸 `-4`；`creo_startup_status` 应在 xtop 已启动但尚未连接时给出可区分的中间态。

### S8. 版本检查把本地 0.3.1 判为 "up_to_date"，无法提示更新

- **现象**：`creo_capabilities.update` 返回 `status:"up_to_date"`、`current_version:0.3.1`、`latest_version:0.3.0`、`message:"当前版本高于最高公开版本，无需降级。"`；`release_url/download_url` 指向 0.3.0。
- **影响**：本地 dev/prerelease 版本永远收不到"有新版本"提示；"无需降级"的措辞也容易误导。
- **建议**： prerelease/本地构建时返回 `local_dev` 之类状态，并把"比较方向"与提示文案区分开。

### S9. `creo_list_components` 与 `creo_capabilities` 输出超过单次返回上限

- **实测**：2 组件装配的 `creo_list_components` 返回 **170 512 字符**；`creo_capabilities` 返回 **98 293 字符**，均被迫落盘。
- **建议**：给 `creo_list_components` 增加 `detail=compact`（仅 feature_id / model_name / transform / placement）；`creo_capabilities` 按 `section` 切分。

### S10. 多操作计划失败后不返回已成功操作清单

- **现象**：8 操作计划在第 2 个失败并整体回滚，`result.operations` 返回 **空数组**，无法知道前 1 个已成功，只能整批重发。
- **建议**：回滚时返回 `operation_outcomes: [{index,label,succeeded}]`。

## 四、正面反馈（本次钣金链路验证通过的项）

1. `creo_sheetmetal_wall` + `creo_sheetmetal_flange` 生成的是**原生钣金特征**：底板 185×232×1（V=42 920 精确）、±X 壁 80 mm R2.54 Y=0.5、门板 155×215×1（V=33 325 精确）。
2. **`sheetmetal_unbend` + `sheetmetal_bend_back` 往返闭环成功**：展开后底板/两壁/格栅/百叶全部摊平可见（见 `box_flat_pattern_preview.jpg`），折回后体积精确复原 —— 这是纯实体方案做不到的，价值很高。
3. 钣金件上的**多环切除**正常（12 条百叶 D 形切口、两侧各 32 个格栅开口一次切除成功，体积增量与解析值吻合）。
4. `creo_execute_plan` 的"首错即停 + 整体回滚 + 落盘快照 + reload 校验"链路可靠，本次十余次失败均未污染模型。
5. 钣金面/边检查输出带 `sheetmetal_type`（壁面/弯折/分区），定位挂接边很方便。

## 六、因上述缺陷而偏离 TXT 直译的替代做法（均已披露）

1. **第二/三段折边（向内 20 框边、向上 8 止口）**：因 S2/S3/S1 无法用钣金折边或增料实现，**本次未建模**（第一轮 `out/` 实体方案里已实现）。
2. **±Y 端壁**：因 S3 无法再挂两道垂直折边、因 S1 无法用增料补壁，**未建模**；故 +Y 端壁 4×⌀30 孔未做。
3. **底板 4 个冲压凸台、2 个铰链座与 2 个 ⌀3 销、门板 2 个铰链耳及 ⌀3.05 盲孔**：均为增料/旋转特征，在钣金件上因 S1 不可用，**未建模**。
4. **格栅**：改用 TXT §6.3 的 **32 个开口直接切除**（每侧 8 中心孔 + 24 环扇孔，120 条草图实体一次切除），反而更贴近原始定义；未经样条替代的环扇孔轮廓按 §6.3 直线+圆弧表达。
5. **百叶**：仅保留 12 条 D 形通风切口；向箱外鼓起的薄壳罩（§5.3）因需增料未建模。
6. **门板**：仅 ±Y 两道 10 mm 折边（±X 因 S3 未做），长圆槽 / 110×40 窗口 / 3×⌀15 已切。

> 以上均为**已披露的近似与缺口**，不构成对原模型的严格几何复现。
