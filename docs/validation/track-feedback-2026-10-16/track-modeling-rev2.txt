三、单位、坐标和缩放
长度单位：毫米(mm)；角度单位：度；体积单位：立方毫米(mm³) 或立方米(m³) 注明。
原点：模型原点，即履带路径草图原点，位于环平面内、底直段中部（大致对应环带底直段中央）。源草图与特征坐标均以它为基准。
X 正方向：沿底直段、由环的左端指向右端（履带行驶/环长方向）。
Y 正方向：在环平面内、垂直于底直段、指向环内侧（环中心方向）。在底直段处，Y+ 朝向环心。
Z 正方向：履带宽度方向，与 X、Y 构成右手系；Z=0 为带宽中心面。
主要平面：环平面 = X-Y 平面（模型"前视基准面"，法线 Z）；带宽中面 = Z=0 平面（即环平面本身）；带体宽度方向沿 Z。
【rev2 新增·关键】截面坐标 v 的基准：附录 B-S01 的截面坐标 v 就是"底直段处的模型 Y"，即 v=0 对应模型 Y=0，**不是**从扫描路径量起。底直段的扫描路径位于 Y=−28.460（v=−28.460），故截面相对路径整体内偏 28.460mm（截面外周 v=−44.893 落在模型 Y=−44.893，与 D002 一致）。扫描是刚性平移，该偏置沿整环恒定。
　若误把 v=0 画在路径上，整条带体会沿径向错位 28.460mm（包围盒 Y、Z 不变但 Y 区间整体下移），务必按本条核对：扫描后带体外周面应落在 Y=−44.893，包围盒 Y 下限 −44.89。
对称性：带体本体、导向槽/双壁、驱动窗口、节距分切均关于 Z=0（环平面）镜像对称；仅胎面凸台为交错（人字）排布，单站不作 Z 镜像对称（见 P05），故整机不严格 Z 对称。
缩放：1:1。
观察约定：从 +Z 俯视（看向 -Z）时，看到环的平面轮廓（长条形环带）；从 -Y 看底直段，看到的是带体外表面（胎面侧）。

四、整体外形、尺度与空间分区
整体形状：一条闭合环形橡胶履带（像一条首尾相接的皮带/坦克履带），环面躺卧在 X-Y 平面内，带宽沿 Z。环呈"长圆形跑道"状：底部一条长直段、顶部一条略倾斜的长直段、两端为圆弧过渡（左端更圆、右端转折稍急）。带体横截面为扁平矩形（宽 457.2mm、厚约 38~58mm），外周（胎面侧）基本平整并布有凸台花纹块，内周（环心侧）中央有一条贯通的导向槽、槽两侧各有一条凸起的导向壁，槽底沿环均匀开有一圈驱动窗口。
主要总尺寸 [实测值，包围盒]：
- 总长（X，含两端凸台）2385.2mm（X 从 -1269.7 到 +1115.4）；
- 总高/环宽（Y）1014.1mm（Y 从 -68.7 到 +945.4）；
- 带宽（Z）457.2mm（Z 从 -228.6 到 +228.6）。
- 环带节线（扫描路径）周长 5424.6mm [推导值]；节距 = 5424.6 / 63 = 86.1048mm/节 [推导值]（正文取 86.10）。
- 标称"节距86mm、63节、总长213.3"：63×86=5418mm=213.3英寸，为节线标称总长（英寸）[推导值]；与实测周长 5424.6mm 基本一致（差 0.1%，因路径取带体截面形心线）。
主要结构和辨识特征：环形带体（P01）、内周中央导向槽+双导向壁（P02）、63 处节距分切（P03）、63 个驱动窗口（P04）、外周胎面凸台（P05，阵列 28 站、84 块）、两端转角凸台（P06，2 站、6 块），合计 30 站 90 块。
沿主方向分区（X 向）：
- 左端圆弧区：X 约 -1269.7 ~ -834.9（含左端转弯）；
- 底直段：X 约 -834.9 ~ +672.5（路径 Y≈-28.46）；
- 右端圆弧区：X 约 +672.5 ~ +1115.4（含右端转弯）；
- 顶直段：连接两端上方，路径从 (+915.7, +409.9) 到 (-626.2, +891.6)，略倾斜。
整体对称性：关于 Z=0 中面对称；X 向左右两端形状不同（左端圆弧更大），不关于 X 对称。

五、主体与各关键部位

P01 带体（环形带本体）
外形和位置：闭合环带，是全部其他结构的基体；由"截面轮廓（草图1）沿闭环路径（履带路径草图）扫描"而成。
参数：带宽 457.2mm [记录值 D2=228.6 半宽×2]；带体径向厚度：中心处 58.49mm、边缘处 38.10mm [记录值/实测值]；扫描路径周长 5424.6mm [推导值]。
基准：截面画在"右视基准面"（Y-Z 平面，法线 +X）；路径画在"前视基准面"（X-Y 平面，法线 +Z）。
　（rev2 注：右视基准面 X=0 与路径仅交于一点，与本扫描并不"相接"，但 SOLIDWORKS 的扫描接受这种配置——已实测通过，见附录 F-1。关键是路径草图必须是一张**单一闭合轮廓**。）
轮廓（带体横截面，截面坐标：横向 u 对应模型 Z，纵向 v 对应模型径向/Y；v 的基准见第三节；数值 mm，[记录值]）：
- 外周（胎面侧，v=-44.89）为一条平直底边，u 从 -222.25 到 +222.25；
- 两端的边（u=±228.6）为竖直短边（v 从 -38.54 到 -13.14），上下各有一道 6.35×6.35mm 的 45° 倒角（D13=D14=6.35）连接到外边和内斜面；
- 内周表面（环心侧）：中心区域（|u|≤92.64）在 v=+13.60 处较平，向两侧斜降到 |u|=145.17 处的 v=-6.79，再平到 |u|=222.25；
- 中央凸起导向结构（见 P02）从内周表面向上伸出。
动作：在右视基准面画上述闭合截面；在前视基准面画闭环路径；用"扫描（实体、合并）"让截面沿路径走一圈成环。
关系：带体是所有切除与凸台的作用对象；切除与凸台均与带体合并/相交为单一实体。
细节：带体左右端边各有 6.35mm 倒角。
允许近似：可用恒定厚度截面近似；但必须保留 ① 中央导向槽与双壁（辨识与啮合特征）② 外周凸台 ③ 驱动窗口。
未知项：内部帘线/钢丝增强无几何，未建。

P02 中央导向槽与双导向壁（内周）
外形和位置：带体内周（环心侧）中央、沿环贯通的导向结构：中间一条凹槽，两侧各一条纵向凸起的导向壁。轮子/驱动齿在槽内运行。
参数（截面坐标 u 对应模型 Z，v 对应模型径向，数值 mm，[记录值]）：
- 槽底在 v=0.00，槽底宽 35.73mm（u=±17.87，D9=17.868）；
- 槽底低于内周表面 13.60mm（内周表面在 v=+13.60）；
- 两侧导向壁内壁自槽底 (±17.87, 0) 斜向升到壁顶内点 (±29.70, 46.17)，故槽口在壁顶处宽 59.40mm（u=±29.70）；
- 壁顶为平顶，各宽 14.49mm（u 从 ±29.70 到 ±44.19），壁顶高 v=+46.17（高出内周表面 32.57mm）；
- 壁外壁自 (±44.19, 46.17) 斜降到 (±48.19, +13.60) 接入内周表面。
参数角色：以上点为轮廓点（截面闭合边界）。
动作：与 P01 同一截面轮廓、同一次扫描成形（不需单独特征）。
关系：导向壁被 P03 的节距分切按每节距切开成 63 段；槽底区域被 P04 的驱动窗口逐节打穿。
允许近似：可把双壁简化为两条等截面纵向筋、槽为矩形槽；必须保留槽的位置、槽底宽 35.7、壁顶高 46.2、槽口宽 59.4 与"贯通整环"。

P03 节距分切（导向壁分段切口，63 处）
外形和位置：沿环每节距（86.10mm，精确取 5424.65/63=86.1056）一处，把中央双导向壁连同槽区横向切开，使导向结构分成 63 段，履带得以在节距处弯折。
参数 [记录值]：切口在前视基准面（X-Y 平面）的截面为梯形：在 v=+13.60（内周表面）处半宽 ±11.11（D1=11.113），在 v=+66.80 处半宽 ±27.09（即切口下窄上宽，宽 22.2mm 到 54.2mm，高 53.2mm，D6=53.204）；切口沿 Z 向（带宽方向）为"中面贯穿"，总深 96.38mm（Z=±48.19，D=96.375），正好覆盖双导向壁宽度（壁外缘 |u|=48.19）。
参数角色：梯形为切口轮廓（减料区）；96.375 为中面双向总深度。
动作：在前视基准面画该梯形（底边在内周表面 v=13.6、顶边在 v=66.8，下窄上宽），沿 Z 向中面贯穿切除带体（两侧各 48.19mm）。
关系：只切到导向壁与槽区（|Z|≤48.19），不切带体主体宽度；与 P04 窗口同站布置。
重复：与 P04 一起由"节距曲线阵列"驱动（见第七节），共 63 处、无跳过。
站位：63 站沿路径弧长等分，间距 = 周长/63 = 86.1056mm；相位取种子位于底直段 X=0 处（见第七节相位规则）。
允许近似：切口可简化为等宽矩形切口（宽 22~54mm、Z 向贯穿导向壁）；必须保留每节距一处、且只切导向结构不切穿带体。

P04 驱动窗口（63 个矩形通孔）
外形和位置：带体中央、每节距一个矩形通孔，穿透带体径向厚度，供驱动轮齿啮合。
参数 [记录值]：窗口在水平截面（上视基准面，X-Z 平面）为矩形：沿 X 宽 28.575mm（±14.2875，D1=28.575），沿 Z 宽 31.08mm（±15.5401）；沿 Y 为中面贯穿，总深 152.4mm（Y=±76.2，D=152.4），保证穿透带体该处径向厚度。
参数角色：矩形为通孔轮廓（减料区）；152.4 为中面双向总深度（大于带厚，即完全穿透）。
动作：在上视基准面画该矩形（中心在模型原点附近、Z=0 中央），沿 Y 中面贯穿切除带体。
关系：位于中央导向槽槽底区（|Z|<15.54，槽底宽 35.73 内）；每节距一个，与 P03 同站。
重复：与 P03 一起由"节距曲线阵列"驱动，共 63 个、无跳过。
允许近似：必须保留数量 63、单孔尺寸 28.575×31.08、逐节距贯通；孔角无圆角（直角）。
等效做法（rev2 补充，已实测）：窗口是"垂直于路径的径向通孔"，其 XY 投影为切向 ±14.2875 的矩形。因此可把 63 个矩形按切向旋转后合入**同一张前视面草图**，沿 Z 中面双向切 31.0802mm——得到的三维减料区与"28.575(X)×31.08(Z) 沿 Y 贯穿"逐个完全相同。合成特征与逐孔特征等价。
实测复核：重建件该 63 窗口已全部生成（拓扑与源一致）。

附录 F：重建实施注意（rev2 新增）
本附录不改变任何几何数值，只记录"按本 TXT 实际动手建"时容易踩的坑。凡与前面正文冲突处，以正文数值为准。

F-1 扫描（P01）
- 真正的前提是"路径草图必须是一张单一闭合轮廓"。用 API 逐段写线/弧时，各段端点必须**逐位相同**才能被合并成一条闭合轮廓；否则轮廓会碎成多段，扫描返回 null（表现为"扫描失败"，很容易误判成轮廓平面位置问题）。
- 截面画在右视基准面（X=0）是可以的，实测通过；该面与路径只交于一点并不影响扫描。切勿为此额外造基准面。
- 自检：扫描后立刻量带体外周面与包围盒，应为外周 Y=−44.893、包围盒 Y 下限 −44.89。若外周跑到 −73.35 一类，说明把截面 v 当成了"从路径量起"（见第三节）。
- 常见 API 陷阱：以“圆心+端点”方式建圆弧的接口有概率**静默丢段**（调用返回成功但草图里少了弧）。务必回读草图，确认弧段数与半径；圆角/浅弧改用三点弧。
- 浅弧（本例 A1 4.21°、A5 3.93°）用三点弧时，中点坐标舍入会明显带偏拟合半径。稳妥做法：弧端点用本 TXT 的原始值（保证与相邻直线端点位对位），弧中点按"圆心 + 半径"高精度算出。

F-2 曲线阵列（PAT01/PAT02/PAT03）
- 若通过 API 调用，某些版本不暴露曲线阵列接口（调用直接返回空）。此时不必放弃，可用**等价原生特征**：
　· P03/P04：环平面是平面，各站梯形/矩形按切向旋转后仍在同一平面内 → 63 站轮廓合入**一张前视面草图**，一次沿 Z 中面切除即可（梯形 ±48.19；矩形按 ±15.5401）；站位按弧长等分 5424.65/63。
　· P05/P06：按第七节"等效站位规则"算出每站站心、切向与法向，逐站建垂直于路径的基准面（面上取"站心、站心+切向×10、站心+Z 向×10"三点），在该面局部坐标里画轮廓后拉伸。站位/朝向与曲线阵列展开结果一致。
- 同一草图内放**大量**独立轮廓做一次切除，在部分环境下会偶发失败（同样的轮廓数这次成功、下次失败，与几何无关）。稳妥做法：按 3 个轮廓一组分特征；某组失败再退化为单轮廓。
- 单草图内多轮廓拉伸有实现限制时，可拆成多张草图、多个特征，几何等价。

F-3 凸台拔模（P05/P06）
- 拔模"外向"= 草图轮廓即最外（尖端）截面，向带体根部放大；用沿拉伸方向的线性偏置来算，偏置量 = 深度×tan(拔模角)。
- 拉伸方向必须指向带体（+Y 一侧）。API 里"是否翻转方向"参数的作用方向由草图面法线决定，建议按"面法线 × 目标径向"的符号判定，比按体积大小猜可靠（弧形段的自由高度会变大，体积阈值会误判）。
- 每建一站都要复核"实体数仍为 1"。方向建反会生成独立实体，此后质量属性读数会变成无效值而不报错。
- 若按 C 深 47.625 建模，25° 外向拔模会让 C 形框 36mm 槽口在约 38.6mm 深处完全闭合，部分内核可能失败；减小拉伸深度（≥22.225 即可，建议 32）不影响外形，见 A03。

F-4 数值一致性
- 弧长间距一律用"周长/N"（86.1056、180.8217），不要用显示值 86.10、180.82 直接累加，否则闭环处分位差会累积。
- 凸台按 A 型/乙型站心交替；判断某站应放 A 还是 B，以"沿环向的站序"为准，不要以站心 X 坐标正负判断（左右端弧段上 X 大小与站序不一致）。
