## 四、关键发现与实现修正

1. **ProMdlFiletypeLoad 对缺件装配不报错。** 实测三次:子件文件全部移走后检索仍返回成功,装配对象入会话、组件静默缺失(会话无子件),首次实现按"检索失败"假设走不到失败分支。已在 native `open_file_native` 增加组件完整性核对(`ProSolidFeatVisit` + `ProAsmcompMdlGet`):组件未全部解析时置 `RETRIEVE_INCOMPLETE` 明确失败,不显示,报告 missing 计数(names 标 unknown)与残留会话对象;完整装配(2/2)核对后正常成功。此发现与修正已按实测记录,不以单测模拟代替。
2. **装配子件经 Creo 搜索规则可从非同目录解析**(工作目录 `build/creo_session/`、受管 output 等可达副本)。该行为符合"沿用 Creo 当前搜索规则,不修改搜索配置"的契约;实测观察到加载来源记录在会话 origin 中。
3. **空窗口 `NO_CURRENT_MODEL`**:会话状态 `current_model_code=-8`(PRO_TK_BAD_CONTEXT,经 SDK 头文件核对)为"无当前模型"而非连接故障;native 已按该码抛 `NO_CURRENT_MODEL` 前缀错误并保留调用名与原码。本轮实机会话窗口在有/无模型间变化,该分支在装配窗口时被 `unsupported_model_type` 前缀路径替代验证(同为稳定原因码改造),无窗口场景留 WorkBuddy 黑盒复验(提示词 A16)。
