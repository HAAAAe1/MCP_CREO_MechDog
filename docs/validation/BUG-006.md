## 复现与修复

用户报告第 7 节 N1 的原始输入为 `axis={"kind":"datum_feature","label":"t82_da1"}`，此前本地校验同样返回 `Pattern requires an axis reference`。现有代码其实已经接受 datum_axis_feature 标签，报告中“只接受几何 id”不完整。根因是 datum_feature 原生解释为基准平面，能力说明中的泛称 datum_label 未明确各工具的几何类型。

新增包内 references.py：在 axis_pattern.axis 上接受报告的通用标签并转换为 datum_axis_feature；几何 axis ID 与明确轴标签保持原样。高层工具 schema 和计划模型共用 PatternAxis，原生收到规范化后的同一引用。没有更改 C++ 或把平面法向自动转换为轴。非法类型、ID/标签和过期 revision 仍拒绝，错误包含完整可操作示例。

capabilities.references 保留旧示例键，补充 syntax、by_tool、轴 ID/标签，并将示例 ID 标明为需替换的演示值。倒圆/倒角集合、钣金裸边、草图坐标支撑包装与 surface_fill 的草图标签分别明确。工具描述和 schema 的字段说明同步；详见 [引用格式](../REFERENCE_SYNTAX.md)。未扩展未经报告支持的任意包装为通用语法。
